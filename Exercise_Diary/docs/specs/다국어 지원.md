# 다국어 지원

## 목적

지금 앱의 모든 화면·문구·음성 안내가 한국어로 고정되어 있다. 영어·일본어·중국어 사용자도 자연스럽게 쓸 수 있도록, 기기 언어 설정에 따라 화면과 음성 안내 언어가 자동으로 바뀌게 하여 앱의 사용자층을 넓힌다.

## 사용자 시나리오

1. 사용자가 기기 언어를 한국어/영어/일본어/중국어 중 하나로 설정해두고 앱을 처음 실행하면, 별도 설정 없이 그 언어로 화면이 표시된다.
2. 기기 언어가 이 4개 언어에 해당하지 않으면(예: 프랑스어, 스페인어 등) 앱은 영어로 표시된다.
3. 홈 화면, 운동 추가, 타이머(매달리기 등 시간형 운동), 횟수·세트 기록, 기록 목록, 앱 사용법 안내까지 모든 화면의 문구가 기기 언어에 맞춰 보인다.
4. 시간형 운동 측정 중 나오는 음성 안내("시작", 초 읽기)도 화면 언어와 같은 언어로 들린다.
5. 측정 중 표시되는 동기부여 문구도 화면 언어에 맞는 문구가 랜덤으로 보인다.
6. 사용자가 직접 입력한 운동 이름(예: "직접 입력"으로 추가한 나만의 운동 이름)은 사용자가 입력한 그대로 표시되고 번역되지 않는다 — 이건 사용자 데이터이지 앱 문구가 아니다.
7. 앱 안에서 언어를 수동으로 바꾸는 메뉴는 이번 버전에는 없다. 언어를 바꾸고 싶으면 기기 자체의 언어 설정을 바꾸면 된다.

## 요구사항

### 언어 감지·적용

1. 앱 실행 시 기기의 언어 설정을 읽어 한국어(ko)/영어(en)/일본어(ja)/중국어(zh) 중 일치하는 언어를 적용한다.
2. 기기 언어가 위 4개 언어 중 어느 것과도 일치하지 않으면 기본값인 영어(en)로 표시한다.
3. 앱 내에 언어를 수동으로 전환하는 UI는 제공하지 않는다 (기기 언어 자동 감지만 지원).

### 화면·UI 문구

4. 다음 화면·컴포넌트에 나타나는 모든 정적 문구(제목, 버튼, 라벨, 안내 문구, 빈 상태 메시지, 확인/취소 다이얼로그, 에러·검증 메시지 포함)가 4개 언어로 번역되어 표시된다: 홈 화면, 운동 추가 화면, 매달리기/시간형 타이머 화면, 횟수·세트 기록 화면, 운동별 기록 목록 화면, 운동 수정 모달, 카메라 권한 모달, 앱 사용법 안내(HelpModal).
5. 프리셋 운동 이름(매달리기, 플랭크, 턱걸이, 팔굽혀펴기, 스쿼트, 런지)은 화면 언어에 맞게 번역되어 표시된다.
6. 사용자가 "직접 입력"으로 추가한 운동 이름은 번역 대상이 아니며, 사용자가 입력한 원문 그대로 어느 언어 설정에서도 동일하게 표시된다.
7. 기록 목록의 날짜 표시(연월일·요일)가 화면 언어에 맞는 표기로 보인다 (요일 이름 등).
8. 측정 단위 라벨(초, 회, 세트, kg, 파운드 등)이 화면 언어에 맞게 표시된다.

### 음성 안내

9. 타이머의 음성 안내("시작" 및 초 읽기)가 화면 언어와 동일한 언어로 재생된다 (한국어→한국어 음성, 영어→영어 음성, 일본어→일본어 음성, 중국어→중국어 음성).

### 동기부여 문구

10. 측정 중 랜덤 표시되는 동기부여 문구가 4개 언어 모두로 번역되어 있고, 화면 언어에 맞는 문구 세트에서 랜덤 표시된다.

## 제외 범위

- 앱 내 수동 언어 전환 설정 화면 — 기기 언어 자동 감지만 지원, 앱 실행 중 기기 언어를 바꾼 경우 앱 재시작 후 반영되어도 무방함
- 한국어/영어/일본어/중국어 외 다른 언어 지원 — 그 외 언어는 모두 영어로 대체 표시
- 사용자가 직접 입력한 운동 이름의 번역 — 사용자 데이터는 원문 그대로 유지
- 우측에서 왼쪽으로 읽는(RTL) 언어 지원 — 대상 4개 언어는 모두 좌→우 표기이므로 해당 없음
- 문구 언어에 따른 화면 레이아웃 자동 조정(예: 긴 번역문에 맞춘 폰트 크기 자동 축소) — 레이아웃 깨짐이 있다면 이번엔 문구 길이 조정으로 대응
- 숫자 표기 방식(천단위 구분자 등) 로케일별 자동 포맷팅 — 기존 숫자 표시 방식 유지, 요일·단위 라벨 등 텍스트만 번역

## 성공 기준

- [ ] `npx tsc --noEmit` 타입 체크 통과
- [ ] 기기 언어를 한국어/영어/일본어/중국어로 각각 바꿔 앱을 실행하면 해당 언어로 화면이 표시된다
- [ ] 기기 언어가 4개 언어 외의 언어(예: 프랑스어)일 때 영어로 표시된다
- [ ] 홈 화면, 운동 추가, 타이머, 횟수·세트 기록, 기록 목록, 앱 사용법 안내의 모든 정적 문구가 4개 언어로 번역되어 있다
- [ ] 프리셋 운동 이름(매달리기·플랭크·턱걸이·팔굽혀펴기·스쿼트·런지)이 화면 언어에 맞게 표시된다
- [ ] 사용자가 직접 입력한 운동 이름은 언어 설정과 무관하게 입력한 원문 그대로 표시된다
- [ ] 기록 목록의 날짜·요일 표기가 화면 언어에 맞게 보인다
- [ ] 타이머 음성 안내가 화면 언어와 같은 언어로 재생된다
- [ ] 측정 중 동기부여 문구가 화면 언어에 맞는 언어로 랜덤 표시된다
- [ ] 앱 내에 언어 수동 전환 UI가 없다

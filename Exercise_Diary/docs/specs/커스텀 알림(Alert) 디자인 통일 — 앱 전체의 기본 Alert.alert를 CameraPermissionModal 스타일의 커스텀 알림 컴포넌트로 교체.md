# 커스텀 알림(Alert) 디자인 통일

## 목적

지금 앱 곳곳(촬영 실패, 유튜브 검색 오류, 안내 영상 삭제 확인, 백업 내보내기·가져오기, 운동 삭제 확인 등)에서 OS 기본 `Alert.alert`가 그대로 쓰이고 있어, 흰 배경·기본 폰트의 시스템 알림창이 앱의 다크+마젠타 테마와 어긋나 보인다. `CameraPermissionModal`에 이미 적용된 테마 카드형 알림 디자인(제목+본문+버튼, 반투명 백드롭)을 앱 전체 알림창의 표준으로 통일해, 어떤 화면에서 알림이 떠도 같은 룩앤필을 갖게 한다.

## 사용자 시나리오

1. 사용자가 촬영 실패, 권한 실패, 유튜브 검색 실패 등 안내만 필요한 상황을 만나면, 테마가 적용된 카드형 알림창이 화면 중앙에 뜨고 버튼 하나("확인")로 닫을 수 있다.
2. 사용자가 안내 영상 삭제, 운동 삭제, 백업 가져오기처럼 실행 여부를 확인해야 하는 동작을 하면, 같은 스타일의 카드형 알림창에 "취소"와 확인/삭제 버튼 두 개가 뜬다. 삭제처럼 되돌릴 수 없는 동작의 버튼은 위험(빨강 계열) 색으로 구분된다.
3. 사용자가 알림창 바깥(백드롭)을 탭하거나 안드로이드 뒤로가기 버튼을 누르면, "취소" 버튼을 누른 것과 같게 동작한다 — 확인 전용 알림은 그냥 닫히고, 삭제 등 확인이 필요한 알림은 아무 동작도 실행되지 않은 채 닫힌다.
4. 사용자는 라이트/다크 테마나 언어(한국어/영어/일본어/중국어) 설정과 무관하게, 모든 알림창에서 항상 같은 디자인 패턴을 보게 된다.

## 요구사항

1. 앱 안에서 `Alert.alert`를 직접 호출하는 모든 지점(`RepsScreen`, `YoutubeSearchButton`, `GuideVideoPanel`, `BackupModal`, `EditExerciseModal`, `useVideoCapture` 훅 — 총 13곳)이 테마가 적용된 카드형 커스텀 알림으로 교체된다. 앱 안 어디에도 OS 기본 `Alert.alert` 호출이 남지 않는다.
2. 커스텀 알림은 제목, 본문 메시지, 버튼 1~2개(확인 전용 / 취소+확인 / 취소+삭제)를 지금의 `Alert.alert` 호출들과 동일한 문구·의미로 그대로 보여준다 — 이번 통일 작업으로 알림 문구나 확인/취소 흐름 자체가 바뀌지는 않는다.
3. 버튼이 하나뿐인 알림(단순 오류 안내)은 "확인" 버튼 하나만 보여주고 누르면 닫힌다.
4. 버튼이 둘인 알림은 "취소"(또는 그에 준하는 닫기 동작)와 실행 버튼을 나란히 보여준다. 실행 버튼이 삭제처럼 되돌릴 수 없는 동작이면 지금의 `EditExerciseModal`/`GuideVideoPanel` 삭제 확인처럼 위험(빨강 계열) 색으로 표시된다.
5. 알림창 바깥(백드롭) 탭 또는 안드로이드 하드웨어 뒤로가기 버튼으로 알림을 닫으면, 파괴적 동작(삭제 등)은 실행되지 않고 "취소"를 누른 것과 동일하게 처리된다. `BackupModal`의 가져오기 확인처럼 닫힘 시점에 로딩 상태(`busy`)를 되돌려야 하는 흐름은 지금과 동일하게 계속 동작한다.
6. 컴포넌트 트리 어디서든(화면, 재사용 컴포넌트, `useVideoCapture` 같은 커스텀 훅 포함) 지금 `Alert.alert(title, message, buttons)`를 호출하던 자리에서 같은 방식으로 커스텀 알림을 띄울 수 있어야 한다.
7. 커스텀 알림은 라이트/다크 테마 색상(`ThemeContext`)을 따르고, 새로 추가되는 버튼 문구("확인" 등)는 4개 언어(한국어/영어/일본어/중국어) 번역 파일에 모두 반영된다.
8. 커스텀 알림이 열려 있는 동안 같은 화면의 다른 모달(예: `EditExerciseModal`, `HelpModal`)과 동시에 뜨는 경우에도 표시가 깨지지 않는다.

## 제외 범위

- OS/네이티브 권한 팝업(카메라 접근 허용 등 시스템이 직접 띄우는 다이얼로그) — 이번 교체 대상은 앱 코드에서 직접 호출하는 `Alert.alert`뿐이다.
- `Alert.prompt`(텍스트 입력형 알림) — 현재 코드베이스에 사용처가 없으므로 다루지 않는다.
- 알림 등장/퇴장 애니메이션을 지금과 다르게 새로 디자인하는 것 — `CameraPermissionModal`과 같은 수준(페이드 인/아웃)이면 충분하다.
- 알림 문구·확인 흐름 자체의 재작성(예: 문구를 더 친절하게 바꾸는 것) — 이번엔 디자인 통일만 다루고 문구는 기존 그대로 옮긴다.
- `Toast`(저장 완료 등 짧은 안내) 컴포넌트 — 이미 커스텀 디자인이 적용되어 있고 이번 작업 대상이 아니다.

## 성공 기준

- [ ] `npx tsc --noEmit` 타입 체크 통과
- [ ] 코드베이스 전체에서 `Alert.alert` 호출이 더 이상 없다 (`grep -rn "Alert.alert" src` 결과 없음)
- [ ] 촬영 실패, 권한 확인 실패, 유튜브 검색 실패 알림이 테마가 적용된 카드형 알림으로 뜬다 (확인 버튼 1개)
- [ ] 안내 영상 삭제, 운동 삭제 확인 알림이 카드형 알림으로 뜨고, 삭제 버튼이 위험(빨강 계열) 색으로 표시된다
- [ ] 백업 내보내기 실패, 가져오기 실패, 가져오기 확인 알림이 카드형 알림으로 뜬다
- [ ] 알림창 바깥을 탭하거나 안드로이드 뒤로가기를 누르면 취소와 동일하게 동작하고, 파괴적 동작은 실행되지 않는다
- [ ] `BackupModal`에서 가져오기 확인 알림을 바깥 탭/뒤로가기로 닫아도 `busy` 상태가 풀려 버튼이 다시 눌린다
- [ ] 라이트/다크 테마를 바꿔가며 확인했을 때 알림창 색상이 테마를 따라간다
- [ ] 새로 추가된 버튼 문구가 4개 언어(한국어/영어/일본어/중국어) 모두에 번역되어 있다

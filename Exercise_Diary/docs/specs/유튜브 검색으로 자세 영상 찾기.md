# 유튜브 검색으로 자세 영상 찾기

## 목적

자세 안내 영상 링크를 등록하려면 사용자가 유튜브 URL을 이미 알고 있어야 한다. 하지만 대부분은 링크를 모르고 검색부터 해야 하므로, 매번 앱을 나가 유튜브에서 운동명을 직접 타이핑해 검색하는 수고가 든다. 영상 링크 입력란 바로 옆에 "운동명 + 자세"로 유튜브 검색을 열어주는 지름길을 제공해 이 수고를 줄인다.

## 사용자 시나리오

1. 측정 화면(타이머 화면 또는 세트 입력 화면)에서 "자세 영상 링크 추가"(또는 수정) 버튼을 눌러 링크 입력 폼을 연다.
2. 입력란 위에 "YouTube에서 검색" 버튼이 보인다.
3. 버튼을 누르면 `현재 운동명 + 자세`(언어별 키워드)로 조합된 검색어로 유튜브 검색 결과가 열린다 — 유튜브 앱이 설치돼 있으면 앱으로, 없으면 브라우저로 열린다.
4. 사용자가 유튜브에서 원하는 영상을 찾아 링크를 복사한 뒤 앱으로 돌아와 입력란에 붙여넣고 저장한다. 이때 앱에 입력해 두었던 다른 값들은 사라지지 않는다.
5. 홈 화면의 운동 수정 모달(EditExerciseModal)과 운동 추가 화면(AddExerciseScreen)의 영상 링크 입력란에도 동일한 검색 버튼이 보인다 — 방금 입력했거나 입력 중인 운동명으로 검색할 수 있다.
6. AddExerciseScreen에서 아직 운동명을 입력하지 않은 상태로 검색 버튼을 누르면, 유튜브로 나가지 않고 이름을 먼저 입력하라는 안내가 표시된다.

## 요구사항

1. 측정 화면(TimerScreen, RepsScreen)의 자세 영상 링크 추가·수정 폼에 "YouTube에서 검색" 버튼이 보인다. *(구현 완료)*
2. 버튼을 누르면 `현재 운동명 + 자세` 검색어로 유튜브 검색 결과를 연다. 유튜브 앱이 설치돼 있으면 앱으로, 아니면 브라우저(웹)로 연다. *(구현 완료, iOS 시뮬레이터 검증 완료)*
3. 운동 추가 화면(AddExerciseScreen)의 영상 링크 입력란 위에도 동일한 검색 버튼이 보이고, 현재 입력 중인 운동명으로 검색을 연다. *(구현 완료)*
4. 운동 수정 모달(EditExerciseModal)의 영상 링크 입력란 위에도 동일한 검색 버튼이 보이고, 현재 운동명으로 검색을 연다. *(구현 완료)*
5. AddExerciseScreen에서 운동명이 비어 있을 때 검색 버튼을 누르면 유튜브를 열지 않고, 이름을 먼저 입력하라는 안내 메시지를 보여준다. *(구현 완료)*
6. 검색어에 쓰이는 "자세" 키워드는 4개 언어(한국어/영어/일본어/중국어) 모두 번역돼 있다. *(구현 완료)*
7. 검색을 위해 화면을 나갔다 돌아와도, 폼에 입력해 두었던 값(운동명, 링크 텍스트 등)은 그대로 유지된다.

## 제외 범위

- 유튜브 검색 결과에서 고른 영상 링크를 자동으로 입력란에 채워주는 기능(인앱 웹뷰로 클릭 캡처 등) — 사용자가 여전히 링크를 수동으로 복사·붙여넣기 해야 한다.
- 검색어에 프리셋별 세부 자세 키워드(예: "스쿼트 무릎 각도")를 넣는 등의 커스터마이징 — 고정된 `운동명 + 자세` 조합만 사용한다.
- 안드로이드 실기기 검증 — 기존 `AndroidManifest`의 `https` VIEW 인텐트 허용 설정으로 동작할 것으로 예상되나, 이번 스펙에서 실기기 확인까지는 다루지 않는다.

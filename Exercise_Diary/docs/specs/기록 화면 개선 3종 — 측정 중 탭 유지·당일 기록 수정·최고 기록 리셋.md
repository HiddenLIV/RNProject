# 기록 화면 개선 3종 — 측정 중 탭 유지·당일 기록 수정·최고 기록 리셋

## 목적

현재 무게·횟수 측정 중 기록 탭으로 전환하면 입력 중이던 세트가 전부 사라지고, 저장된 기록은 완료 즉시 완전히 고정돼 사후 수정이 불가능하며, 최고 기록은 항상 전체 기간을 통틀어 계산돼 컨디션 난조·부상 복귀 등으로 다시 시작하는 사용자가 예전 최고 기록에 눌려 동기를 잃기 쉽다. 이 세 가지 마찰을 줄여 측정 흐름을 끊김 없이, 기록 입력 실수를 유연하게 바로잡을 수 있게, 최고 기록을 다시 도전 가능한 목표로 만든다.

## 사용자 시나리오

**시나리오 1 — 측정 중 탭 전환**
1. 사용자가 턱걸이 측정 화면에서 세트 3개를 등록하고 4번째 세트의 횟수·무게를 입력하는 중이다.
2. 저장하지 않고 상단 "기록" 탭을 눌러 지금까지 쌓인 기록 목록을 확인한다.
3. 다시 "측정" 탭으로 돌아오면, 등록해뒀던 세트 3개와 입력 중이던 4번째 세트 값이 그대로 남아있다. 촬영해둔 영상, 진행 중이던 세트 간 휴식 타이머도 마찬가지다.
4. 세트를 이어서 등록하고 저장한다.

**시나리오 2 — 당일 기록 수정**
1. 사용자가 오늘 팔굽혀펴기 3세트를 측정해 저장했다.
2. 기록 탭에서 오늘 저장한 기록을 열어보니 두 번째 세트의 횟수를 잘못 입력한 것을 발견한다.
3. 그 기록을 수정 모드로 열어 두 번째 세트의 횟수를 고치고, 빠뜨렸던 세트를 하나 추가한 뒤 저장한다.
4. 목록과 (해당되면) 최고 기록이 수정된 값 기준으로 즉시 갱신된다.
5. 다음날, 어제 저장한 기록을 열어보면 더 이상 값을 고칠 수 없고 조회와 삭제만 가능하다.
6. (시간형도 동일) 오늘 측정한 매달리기 기록의 시간 값을 기록 목록에서 다시 고칠 수 있고, 날짜가 바뀌면 수정할 수 없다.

**시나리오 3 — 최고 기록 리셋**
1. 부상 후 복귀한 사용자에게 예전 최고 기록(50회)이 한동안 넘기 어려운 목표로 느껴진다.
2. 기록 탭에서 "최고 기록 리셋"을 실행하면 확인 알림이 뜨고, 확인을 누른다.
3. 리셋 직후 최고 기록 카드는 "리셋 이후 기록 없음" 상태로 바뀌고, 과거 기록 목록(50회 포함)은 그대로 남아있다.
4. 이후 측정한 기록 중 가장 높은 값이 새로운 최고 기록으로 표시된다(리셋 이전 기록은 최고 기록 후보에서 제외된다).

## 요구사항

1. 무게·횟수 측정 화면에서 저장하지 않은 상태(등록된 세트 목록, 현재 입력 중인 횟수·무게, 수정 중이던 세트 인덱스, 촬영된 영상, 진행 중인 세트 간 휴식 타이머)로 기록 탭으로 전환했다가 측정 탭으로 돌아오면 모든 값이 전환 전과 동일하게 남아있다.
2. 1번의 유지는 같은 운동 화면 안에서 측정↔기록 탭만 오가는 경우에 한한다 — 운동 화면 자체를 벗어났다가(예: 홈으로 나갔다가) 같은 운동으로 재진입한 경우, 또는 앱을 종료했다 다시 연 경우까지 보장하지 않는다.
3. 기록 목록에서 오늘(기기 로컬 날짜 기준) 저장된 기록은 운동 유형에 관계없이 값을 수정할 수 있다.
   - 횟수·세트형: 측정 화면과 동일한 방식으로 각 세트의 무게·횟수 값을 고치거나, 세트를 추가·삭제할 수 있다.
   - 시간형: 기록된 시간 값을 다시 고칠 수 있다.
4. 오늘이 아닌(어제 이전) 날짜에 저장된 기록은 값 수정이 불가능하다 — 기존과 동일하게 조회와 삭제만 가능하다.
5. 자정이 지나 날짜가 바뀌면, 전날 저장된 기록은 (화면 재진입 시 기준으로) 더 이상 수정 가능한 상태로 표시되지 않는다.
6. 수정한 값은 저장 즉시 기록 목록과 최고 기록 계산에 반영된다.
7. 운동별로 "최고 기록 리셋"을 실행할 수 있다. 실행해도 실제 측정 기록(목록의 각 항목)은 전혀 삭제되지 않는다.
8. 리셋을 실행하면 그 시점 이후에 측정된 기록만 최고 기록 계산 대상이 된다 — 리셋 이전 기록은 목록엔 남아있지만 더 이상 "최고 기록"으로 표시되지 않는다.
9. 리셋 직후 리셋 시점 이후의 기록이 하나도 없으면, 최고 기록 카드는 값이 없는 상태(예: "리셋 이후 기록 없음")로 표시된다.
10. 리셋 이후 새로 측정한 기록이 하나라도 생기면, 그중 가장 높은 값이 최고 기록으로 표시된다.
11. 리셋은 되돌릴 수 없는 동작이므로 실행 전 확인 알림을 거친다.
12. 리셋은 운동별로 독립적으로 적용된다 — 한 운동에서 리셋해도 다른 운동의 최고 기록·기록 목록에는 영향이 없다.

## 제외 범위

- 운동 화면을 완전히 벗어났다가(홈 이동 등) 돌아오거나 앱을 종료 후 재실행했을 때 측정 중이던 미저장 세트를 복구하는 것 — 이번엔 같은 운동 화면 안에서의 탭 전환만 다룬다
- 오늘이 아닌 과거 날짜 기록의 사후 수정 — 여전히 제외한다(당일에 한함)
- 최고 기록 리셋의 되돌리기(리셋 취소, 이전 기준 시점 복원)
- 리셋 이력 표시(언제 리셋했는지 히스토리 목록 등)
- 실제 기록(row) 자체를 삭제하는 방식의 "리셋" — 기준 시점 재설정 방식으로 확정했으므로 데이터 삭제 방식은 다루지 않는다
- 세트 수정 중 영상을 새로 촬영하거나 기존 영상을 교체하는 기능

## 성공 기준

- [ ] `npx tsc --noEmit` 타입 체크 통과
- [ ] 측정 화면에서 세트를 등록하고 입력칸에 값이 남은 채로 기록 탭 → 측정 탭으로 돌아오면 등록된 세트 목록과 입력 중이던 값이 그대로 남아있다
- [ ] 세트 간 휴식 타이머가 진행 중일 때 탭을 전환했다가 돌아와도 타이머가 계속 진행돼 있다(끊기거나 초기화되지 않는다)
- [ ] 촬영해둔 영상이 탭 전환 후에도 계속 첨부돼 있다
- [ ] 오늘 저장한 횟수·세트형 기록을 기록 탭에서 열어 세트 값을 고치고 세트를 추가/삭제한 뒤 저장하면 목록에 반영된다
- [ ] 오늘 저장한 시간형 기록을 기록 탭에서 열어 시간 값을 고치면 목록에 반영된다
- [ ] 어제 이전 날짜의 기록에는 수정 진입점이 보이지 않거나 비활성화돼 있다
- [ ] 수정 후 그 값이 기존 최고 기록보다 높아지면 최고 기록 카드가 갱신된다
- [ ] "최고 기록 리셋" 실행 전 확인 알림이 뜨고, 취소하면 아무 것도 바뀌지 않는다
- [ ] 리셋을 실행해도 기록 목록의 항목 수·내용이 변하지 않는다(삭제되지 않는다)
- [ ] 리셋 직후 최고 기록 카드가 "기록 없음" 상태로 바뀐다
- [ ] 리셋 이후 새 기록을 측정하면 그 값이 최고 기록으로 표시된다
- [ ] 리셋 이전의 더 높은 과거 기록이 있어도 리셋 이후엔 최고 기록으로 다시 표시되지 않는다
- [ ] 한 운동에서 리셋해도 다른 운동의 최고 기록·기록 목록은 영향받지 않는다

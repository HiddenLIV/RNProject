# 로컬 알림 리마인더

## 목적

지금은 사용자가 앱을 며칠 안 열어도 그걸 알려주는 장치가 전혀 없다 — 잊으면 그걸로 끝이다. 사용자가 설정에서 원하는 방식(매일 정해진 시각 / N일간 미기록 시)으로 리마인더 알림을 켜서, 운동 습관이 끊기지 않게 스스로 다시 켜고 싶어지는 계기를 만든다. 서버로 아무것도 전송하지 않는 순수 기기 로컬 알림이다.

## 사용자 시나리오

1. 사용자가 홈 화면의 설정(⚙️)을 열면 "챙김 알림" 섹션이 보인다. 기본값은 꺼짐.
2. 토글을 켜면 알림 방식을 고른다 — **매일 정해진 시각** 또는 **N일간 운동 기록이 없을 때**(기본은 매일 정해진 시각).
   - 매일 정해진 시각을 고르면 알림을 받을 시각(시:분)을 고른다. 기본값은 오후 8시.
   - N일간 미기록을 고르면 며칠 뒤부터 알릴지(1~14일, 기본 3일)와 그날 알릴 시각(시:분, 기본 오후 8시)을 고른다.
3. 토글을 처음 켤 때 시스템 알림 권한을 요청하는 대화상자가 뜬다. 허용하면 설정한 방식대로 알림이 예약된다.
4. 권한을 거부한 채로 토글을 켜려 하면, 알림을 받으려면 기기 설정에서 권한을 켜야 한다는 안내가 뜬다(기기 설정 화면으로 바로 이동하는 버튼 포함). 토글은 다시 꺼짐 상태로 남는다.
5. **매일 정해진 시각** 모드: 실제로 운동을 했는지와 무관하게, 매일 그 시각에 "오늘 운동할 시간이에요" 같은 동기부여 알림이 온다.
6. **N일간 미기록** 모드: 어떤 운동이든 가장 최근에 기록을 남긴 날짜를 기준으로, 그로부터 설정한 일수가 지나도록 새 기록이 없으면 설정한 시각에 "며칠째 쉬고 있어요" 같은 알림이 온다. 그 사이에 아무 운동이든 새로 기록하면 카운트가 그 시점부터 다시 시작된다(알림도 그만큼 뒤로 밀린다). 기록이 하나도 없는 사용자는 이 옵션을 켠 시점을 기준으로 카운트가 시작된다.
7. 알림을 탭하면 앱이 열린다(홈 화면).
8. 설정에서 방식·시각·일수를 바꾸면 다음 계산부터 즉시 새 설정이 반영된다.
9. 토글을 끄면 예약된 알림이 전부 취소되고, 이후 새로 기록을 남겨도 알림이 다시 잡히지 않는다.
10. 앱을 지웠다 다시 깔거나 기기를 바꾸면 알림 설정은 유지되지 않는다(로컬 저장이므로 다른 로컬 설정과 동일하게 취급).

## 요구사항

1. 설정 화면에 "챙김 알림" 켜기/끄기 토글이 있다. 기본값은 꺼짐.
2. 토글이 켜진 상태에서만 방식 선택(매일 정해진 시각 / N일간 미기록)과 그에 딸린 세부 설정(시각, 일수)이 보인다.
3. **매일 정해진 시각** 모드는 사용자가 시:분을 직접 고를 수 있다. 기본값은 20:00.
4. **N일간 미기록** 모드는 일수(1~14, 기본 3)와 알릴 시각(시:분, 기본 20:00)을 사용자가 고를 수 있다.
5. 토글을 켜는 시점에 알림 권한이 없으면 시스템 권한 요청을 띄운다. 허용해야 알림이 예약되고 토글이 켜진 상태로 유지된다.
6. 알림 권한이 이미 거부된 상태(다시 묻지 않음 등)에서 토글을 켜려 하면 기기 설정으로 안내하는 커스텀 알림을 보여주고, 토글은 꺼짐 상태로 남는다.
7. 매일 정해진 시각 모드에서는 설정한 시각에 매일 알림이 울린다(실제 운동 여부와 무관).
8. N일간 미기록 모드에서는 시간형·횟수형을 가리지 않고 앱에 있는 모든 운동을 통틀어 가장 최근 기록 시각을 기준으로, 설정한 일수가 지난 뒤 설정한 시각에 알림이 울린다.
9. N일간 미기록 모드에서 어떤 운동이든 새 기록이 저장되면, 그 시점을 기준으로 다음 알림 예약이 다시 계산된다(카운트 리셋).
10. N일간 미기록 모드를 켰을 때 기존 기록이 하나도 없다면, 토글을 켠 시점을 기준으로 카운트가 시작된다.
11. 방식·시각·일수를 바꾸면 이전에 예약된 알림은 취소되고 새 설정으로 다시 예약된다.
12. 토글을 끄면 예약돼 있던 알림이 즉시 취소된다.
13. 알림을 탭하면 앱이 열린다.
14. 이 설정은 특정 운동이 아니라 앱 전체에 공통으로 적용되는 단일 설정이다.
15. 설정은 기기에 저장되어 앱을 재시작해도 유지된다.
16. 알림 문구와 설정 화면의 라벨은 4개 지원 언어(ko/en/ja/zh) 모두 번역되어 표시된다.

## 제외 범위

- 서버 푸시 알림 — 전부 기기 로컬 예약 알림이며, 서버로 아무 데이터도 전송하지 않는다
- 운동별로 다른 리마인더를 따로 설정하는 기능 — 앱 전체 공통 설정 하나로 제한한다
- 하루에 여러 번 알림을 보내는 기능 — 두 방식 모두 하루 한 번, 한 시각만 지원한다
- 알림 문구를 사용자가 직접 편집하는 기능 — 이번엔 고정 문구(언어별 번역)만 제공한다
- 요일별로 알림을 켜고 끄는 기능(예: 주말 제외) — 이번 범위에서는 매일 동일하게 적용된다
- N일간 미기록 모드에서 "어떤 운동을 기준으로 할지" 개별 선택 — 앱에 있는 모든 운동을 통틀어 가장 최근 기록만 본다
- 알림 도착 이력을 앱 안에서 목록으로 보여주는 기능

## 성공 기준

- [ ] `npx tsc --noEmit` 타입 체크 통과
- [ ] 설정 화면에 리마인더 알림 토글이 보이고 기본값은 꺼짐이다
- [ ] 토글을 켜면 방식 선택(매일 정해진 시각 / N일간 미기록)이 보인다
- [ ] 매일 정해진 시각 모드에서 시:분을 선택할 수 있고 기본값은 20:00이다
- [ ] N일간 미기록 모드에서 일수(1~14, 기본 3)와 시:분(기본 20:00)을 선택할 수 있다
- [ ] 권한이 없는 상태에서 토글을 켜면 시스템 권한 요청이 뜬다
- [ ] 권한을 허용하면 토글이 켜진 채로 유지되고 알림이 예약된다
- [ ] 권한을 거부하면 기기 설정으로 안내하는 화면이 뜨고 토글은 꺼짐으로 남는다
- [ ] 매일 정해진 시각 모드에서 설정한 시각에 알림이 온다(실기기 확인)
- [ ] N일간 미기록 모드에서, 설정한 일수 동안 새 기록이 없으면 설정한 시각에 알림이 온다(실기기 확인 또는 예약된 알림의 트리거 시각 검증)
- [ ] N일간 미기록 모드에서 새 기록을 저장하면 다음 예약 알림 시각이 그 시점 기준으로 다시 계산된다
- [ ] 방식·시각·일수를 바꾸면 이전 예약이 취소되고 새 설정으로 재예약된다
- [ ] 토글을 끄면 예약된 알림이 취소된다
- [ ] 알림을 탭하면 앱이 열린다
- [ ] 앱을 재시작해도 리마인더 설정(켜짐 여부·방식·시각·일수)이 유지된다
- [ ] 설정 라벨과 알림 문구가 한국어·영어·일본어·중국어 모두 번역되어 보인다

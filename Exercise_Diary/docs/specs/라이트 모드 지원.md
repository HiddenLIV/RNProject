# 라이트 모드 지원

## 목적

지금 앱은 `app.json`의 `userInterfaceStyle: "dark"` 설정 때문에 기기의 디스플레이 설정과 무관하게 항상 다크 배경으로 고정돼 있다. 안드로이드(및 iOS) 시스템의 라이트/다크 설정을 그대로 따라가게 하여, 라이트 모드를 선호하는 사용자도 시스템과 일관된 화면으로 앱을 쓸 수 있게 한다.

## 사용자 시나리오

1. 기기의 디스플레이 설정이 "다크"면, 앱은 지금과 동일한 다크 배경으로 보인다.
2. 기기의 디스플레이 설정을 "라이트"로 바꾸면, 앱도 밝은 배경·어두운 텍스트로 전환된다.
3. 앱을 실행해 둔 채로 기기 설정을 바꿔도, 앱을 다시 켤 필요 없이 화면이 바로 전환된다.
4. 앱 안에는 라이트/다크를 고르는 별도 토글이나 설정 화면이 없다 — 오직 기기 설정만 따른다.
5. 포인트 컬러 프리셋(기본·오렌지·민트·레드·블루) 5종은 라이트 모드에서도 그대로 선택할 수 있고, 골라둔 프리셋은 라이트/다크 전환과 무관하게 유지된다.
6. 라이트 모드에서도 홈, 운동 추가/수정, 매달리기 타이머, 기록 화면 등 모든 화면에서 배경과 텍스트의 대비가 충분해 내용을 읽는 데 문제가 없다.

## 요구사항

1. 기기 시스템 디스플레이 설정이 "다크"면 앱은 다크 배경 팔레트(지금과 동일한 톤)로 표시된다.
2. 기기 시스템 디스플레이 설정이 "라이트"면 앱은 밝은 배경 팔레트로 표시된다.
3. 앱이 실행 중인 상태에서 시스템 설정이 바뀌면, 앱 재시작 없이 화면이 즉시 반영된다.
4. 라이트·다크 각각에 배경/카드/카드(연한)/구분선/텍스트(기본·보조·희미)/경고색이 별도로 정의돼 있고, 어느 모드에서도 텍스트-배경 명암 대비가 충분해 읽기 쉽다 (구체적 색상 값과 대비 기준은 /design에서 결정).
5. 포인트 컬러 프리셋 5종(기본·오렌지·민트·레드·블루)은 라이트·다크 모드 각각에서 모두 선택 가능하며, 프리셋 선택 상태는 라이트/다크 전환과 무관하게 그대로 유지된다.
6. 앱 안에는 라이트/다크를 수동으로 고르는 토글이나 설정 화면이 없다 — 기기 시스템 설정만 따른다.
7. 상태표시줄(StatusBar) 아이콘 색도 라이트/다크 모드에 맞게 자동 전환되어, 어느 모드에서도 배경과 구분되어 보인다.

## 제외 범위

- 앱 내 라이트/다크 수동 선택 토글·설정 화면 (이번엔 시스템 설정 자동 반영만 지원)
- 라이트 모드용 새로운 레이아웃·타이포그래피 변경 — 색상 팔레트 전환 외 구조 변경은 없음
- 앱 아이콘의 라이트/다크 배리언트 — 아이콘은 이번에도 다루지 않는다 (기존 테마 컬러 기능과 동일한 제외 방침)
- 라이트/다크 미지원 구형 OS에 대한 별도 폴백 로직 — 시스템 API의 기본 동작을 그대로 따른다
- iOS 별도 검증 — 동일한 API(시스템 컬러 스킴)라 자연스럽게 동작할 것으로 예상되나, 이번 성공 기준 검증은 안드로이드 기준으로 진행한다

## 성공 기준

- [ ] `npx tsc --noEmit` 타입 체크 통과
- [ ] 기기 시스템 설정을 다크로 바꾸면 앱이 다크 배경으로 보인다
- [ ] 기기 시스템 설정을 라이트로 바꾸면 앱이 밝은 배경으로 보인다
- [ ] 앱 실행 중 시스템 설정을 바꾸면 재시작 없이 화면이 바로 전환된다
- [ ] 라이트·다크 각 모드에서 홈/운동 추가·수정/타이머/기록 화면 전체에 걸쳐 텍스트가 배경과 뚜렷이 구분되어 읽기 쉽다
- [ ] 포인트 컬러 프리셋 5종이 라이트·다크 각각에서 정상적으로 선택·적용된다
- [ ] 라이트/다크 전환과 무관하게 이전에 고른 포인트 컬러 프리셋이 그대로 유지된다
- [ ] 앱 안에 라이트/다크를 고르는 수동 토글이 없다 (기기 설정만 따름)
- [ ] 상태표시줄 아이콘이 두 모드 각각의 배경에서 잘 보인다

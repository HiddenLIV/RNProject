# 타이머 알림 무음 기능

## 목적

지금은 측정 중 매초 숫자를 읽어주는 음성 안내(카운트다운, "시작", 매초 숫자 읽기)가 항상 켜져 있어 헬스장 탈의실, 도서관, 사무실처럼 조용해야 하는 장소에서는 부담스럽거나 주변에 방해가 될 수 있다. 사용자가 원할 때 음성 안내를 꺼서 어디서든 부담 없이 앱을 쓸 수 있게 한다. (진행 상황을 놓치지 않게 해주는 벨소리는 이번 범위에서는 그대로 유지한다.)

## 사용자 시나리오

1. 사용자가 측정 화면(TimerScreen)에서 측정을 시작하기 전, 지금 "준비 카운트다운"·"벨 간격"이 있는 설정 카드에 "음성 안내" on/off 토글이 추가로 보인다.
2. 기본값은 켜짐(현재 동작과 동일) — 처음 쓰는 사용자는 지금과 똑같이 음성 안내를 듣는다.
3. 사용자가 토글을 꺼서 무음으로 바꾸고 측정을 시작하면, 카운트다운 초 읽기, 측정 시작 시 "시작" 발화, 측정 중 매초 숫자 읽기가 전부 나오지 않는다. 벨 간격마다 울리는 벨소리는 토글과 무관하게 그대로 울린다.
4. 이 설정은 특정 운동에 종속되지 않고 앱 전체에 공통으로 적용된다 — 한 운동에서 토글을 바꾸면 다른 운동의 측정 화면을 열어도 같은 상태로 보이고 적용된다.
5. 앱을 껐다 다시 켜도 마지막으로 설정한 토글 상태가 그대로 유지된다.
6. 측정이 시작되면 설정 카드 대신 진행 UI(경과 시간·정지 버튼 등)가 뜨는 기존 동작은 그대로이므로, 측정 도중에는 음성 안내를 껐다 켤 수 없다 — 다음 측정부터 바뀐 설정이 반영된다.

## 요구사항

1. 측정 화면의 설정 카드(카운트다운·벨 간격이 있는 카드)에 "음성 안내" on/off 토글이 추가된다.
2. 토글을 끄면 아래 TTS 발화가 전부 억제된다.
   - 카운트다운 중 초 읽기 (예: 5, 4, 3, 2, 1)
   - 측정 시작 시 "시작" 발화
   - 측정 중 매초 숫자 읽기
3. 벨 간격마다 울리는 벨소리(`bell.wav`)는 음성 안내 토글 상태와 무관하게 항상 그대로 울린다.
4. 토글 상태는 운동별 설정(카운트다운 시간, 벨 간격)과 달리 앱 전체에 공통으로 적용되는 단일 설정이다 — 어떤 운동의 측정 화면을 열어도 동일한 값이 보이고 적용된다.
5. 토글 상태는 기기에 저장되어 앱을 재시작해도 유지된다.
6. 최초 설치 시 기본값은 켜짐(음성 안내 있음)이다 — 기존 사용자 경험을 바꾸지 않고 시작한다.
7. 토글을 끈 상태에서도 화면의 시각 요소(경과 시간 숫자, 동기부여 문구, 정지 버튼 등)는 지금과 동일하게 보인다 — 달라지는 것은 음성 출력뿐이다.
8. 토글 라벨과 관련 문구는 4개 지원 언어(ko/en/ja/zh) 모두 번역되어 표시된다.

## 제외 범위

- 벨소리 자체를 끄는 기능 — 이번엔 음성 안내만 대상이며, 벨소리는 항상 유지한다
- 운동별로 서로 다른 무음 설정을 갖는 기능 — 앱 전체 공통 설정 하나로 제한한다
- 측정이 진행되는 도중 실시간으로 음성 안내를 껐다 켰다 하는 빠른 토글/버튼 — 측정 시작 전 설정 카드에서만 변경 가능하다
- 기기 자체의 무음 모드(벨소리 스위치)·시스템 볼륨과의 연동
- 진동(Haptic) 피드백 추가 — 현재 진동 피드백 자체가 없으므로 이번 범위에서 다루지 않는다

## 성공 기준

- [ ] `npx tsc --noEmit` 타입 체크 통과
- [ ] 측정 화면 설정 카드에 "음성 안내" 토글이 보인다
- [ ] 토글을 끈 채로 측정을 시작하면 카운트다운 초 읽기, "시작" 발화, 매초 숫자 읽기가 들리지 않는다
- [ ] 토글을 끈 상태에서도 벨 간격마다 벨소리는 정상적으로 울린다
- [ ] 한 운동에서 토글을 끄면 다른 운동의 측정 화면을 열어도 꺼진 상태로 보인다
- [ ] 앱을 재시작해도 마지막으로 설정한 토글 상태가 유지된다
- [ ] 최초 설치 시 토글은 켜짐 상태다
- [ ] 토글 라벨이 한국어·영어·일본어·중국어 모두 번역되어 보인다

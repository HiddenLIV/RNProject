# 첫 실행 온보딩 안내 및 홈 화면 빈 상태 안내 개선

## 목적

지금은 앱 사용법을 홈 화면의 물음표(도움말) 아이콘을 직접 눌러야만 알 수 있어, 처음 쓰는 사용자가 그 존재 자체를 놓치기 쉽다. 앱을 처음 실행했을 때 핵심 사용 흐름을 자동으로 짧게 보여주고, 운동이 하나도 없는 홈 화면에도 다음에 뭘 해야 할지 시각적으로 안내해 처음 쓰는 사용자가 헤매지 않게 한다.

## 사용자 시나리오

1. 사용자가 앱을 설치하고 처음 실행하면, 홈 화면이 뜨기 전에(또는 뜬 직후) 온보딩 화면이 자동으로 나타난다.
2. 온보딩은 5장으로 구성되며, 좌우로 넘기며 볼 수 있다: ① 운동 추가, ② 측정 시작, ③ 기록 확인, ④ 운동 촬영, ⑤ 자세 안내 영상. 각 장은 아이콘(또는 간단한 그림)과 한두 문장의 설명으로 구성된다.
3. 아무 때나 "건너뛰기"를 눌러 온보딩을 닫고 바로 홈 화면으로 갈 수 있다. 마지막 장에서는 "시작하기" 버튼으로 닫는다.
4. 온보딩을 한 번 보고 나면, 이후 앱을 다시 실행해도 자동으로 뜨지 않는다.
5. 나중에 다시 보고 싶으면, 홈 화면의 도움말 모달 안에 있는 "온보딩 다시보기" 버튼을 눌러 같은 온보딩을 다시 볼 수 있다 (이때는 "건너뛰기"/"시작하기"를 누르면 그냥 도움말 화면으로 돌아간다).
6. 등록된 운동이 하나도 없는 상태로 홈 화면을 보면, 기존 "운동 추가" 카드 위에 "아직 등록된 운동이 없어요. 첫 운동을 추가해보세요" 같은 안내 문구와 아이콘이 보인다. 운동을 하나라도 추가하면 이 안내는 사라지고 평소의 운동 목록 화면으로 바뀐다.

## 요구사항

### 온보딩

1. 앱을 기기에 설치한 뒤 처음 실행하면 온보딩 화면이 자동으로 표시된다.
2. 온보딩은 5장이며, 각 장은 ① 운동 추가, ② 측정 시작, ③ 기록 확인, ④ 운동 촬영, ⑤ 자세 안내 영상 순서로 핵심 사용법을 한두 문장으로 설명한다 (내용은 기존 도움말(HelpModal)의 해당 항목 설명을 요약해 재사용한다).
3. 장 사이는 좌우로 스와이프하거나 다음 버튼으로 넘길 수 있고, 지금 몇 번째 장인지 보여주는 표시(점 등)가 있다.
4. 어느 장에서든 "건너뛰기"를 눌러 즉시 온보딩을 닫을 수 있다.
5. 마지막 장에는 "건너뛰기" 대신 "시작하기" 버튼이 있어 온보딩을 닫는다.
6. 온보딩을 한 번이라도 닫으면(건너뛰기든 끝까지 봤든) 그 사실이 기기에 저장되어, 앱을 다시 실행해도 자동으로 다시 뜨지 않는다.
7. 홈 화면의 도움말(HelpModal) 안에 "온보딩 다시보기" 버튼이 있어, 언제든 같은 온보딩 5장을 다시 볼 수 있다.
8. "다시보기"로 연 온보딩에서 닫으면(건너뛰기/시작하기 모두) 도움말 화면으로 돌아간다 — 첫 실행 자동 노출 여부 저장 상태에는 영향을 주지 않는다(이미 본 것으로 처리된 상태이므로 값이 바뀔 일이 없다).

### 홈 화면 빈 상태 안내

9. 등록된 운동이 하나도 없을 때, 홈 화면의 "운동 추가" 카드 위(또는 그 자리)에 안내 아이콘과 "아직 등록된 운동이 없어요. 첫 운동을 추가해보세요" 같은 문구가 보인다.
10. 이 안내 문구 자체는 탭해도 아무 동작이 없다 — 운동 추가는 기존처럼 "운동 추가" 카드를 탭해서 진행한다.
11. 운동을 하나라도 추가하고 나면 이 안내는 더 이상 보이지 않고, 운동 목록이 평소처럼 표시된다.

## 제외 범위

- 온보딩 각 장에 실제 촬영된 스크린샷·동영상 삽입 — 이번엔 아이콘과 텍스트로만 구성한다.
- 온보딩 중 실제 기능을 미리 체험해보는 인터랙티브 튜토리얼(예: 실제로 운동을 추가해보게 하는 것) — 이번엔 보기만 하는 정적 안내다.
- 빈 상태 안내에 애니메이션이나 일러스트 이미지 — 아이콘과 텍스트만 사용한다.
- 운동을 모두 삭제해서 다시 0개가 됐을 때 온보딩이 자동으로 다시 뜨는 것 — 온보딩 자동 노출은 기기 최초 실행 1회로 한정하고, 빈 상태 안내(요구사항 9)만 그 상황에서 다시 보인다.
- 다국어 번역 문안의 구체적 표현 — 기존 4개 언어 번역 체계에 맞춰 추가하되, 세부 문구는 /dev 단계에서 정한다.

## 성공 기준

- [ ] `npx tsc --noEmit` 타입 체크 통과
- [ ] 앱을 처음 설치해 실행하면 온보딩이 자동으로 뜬다
- [ ] 온보딩이 5장(운동 추가/측정 시작/기록 확인/운동 촬영/자세 안내 영상)으로 구성되어 있고 좌우로 넘길 수 있다
- [ ] 아무 장에서나 "건너뛰기"로 온보딩을 닫을 수 있다
- [ ] 마지막 장의 "시작하기"로 온보딩을 닫을 수 있다
- [ ] 온보딩을 한 번 닫은 뒤 앱을 재실행하면 자동으로 다시 뜨지 않는다
- [ ] 홈 화면 도움말 안에 "온보딩 다시보기" 버튼이 있고, 눌러서 같은 온보딩을 다시 볼 수 있다
- [ ] "다시보기"로 연 온보딩을 닫으면 도움말 화면으로 돌아간다
- [ ] 운동이 0개인 홈 화면에 안내 아이콘+문구가 보인다
- [ ] 운동을 하나 추가하면 그 안내가 사라지고 평소 목록 화면으로 바뀐다
- [ ] 새로 추가된 문구가 4개 언어(한국어/영어/일본어/중국어) 모두에 번역되어 있다

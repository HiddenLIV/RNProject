# 측정 화면에서 자세 안내 영상 링크 추가

## 목적

지금은 이미 등록된 자세 안내 영상만 측정 화면에서 재생할 수 있고, 링크가 없는 운동은 홈 화면으로 나가 연필 아이콘으로 운동 수정 모달을 열어야만 링크를 등록할 수 있다. 이 왕복을 없애고 측정 화면에서 곧바로 링크를 등록할 수 있게 해, 자세 안내 영상 기능을 쓰는 데 걸리는 걸음 수를 줄인다.

## 사용자 시나리오

1. 자세 안내 영상 링크가 없는 운동의 측정 화면(타이머 화면 또는 세트 입력 화면) 상단에, 기존 "자세 영상 보기" 버튼 자리에 대신 "자세 영상 링크 추가" 버튼이 보인다.
2. 버튼을 탭하면 그 자리에 유튜브 링크 입력란과 저장·취소 버튼이 펼쳐진다.
3. 유튜브 링크(watch, youtu.be, shorts 형태 모두)를 붙여넣고 저장하면, 그 자리가 곧바로 기존의 "자세 영상 보기" 토글 버튼으로 바뀐다 — 화면을 나갔다 들어올 필요 없이 바로 눌러서 재생할 수 있다.
4. 유튜브 링크 형식이 아니면 저장이 거부되고 안내 메시지가 보인다.
5. 취소를 누르면 입력한 내용 없이 원래의 "자세 영상 링크 추가" 버튼 상태로 돌아간다.
6. 시간형 운동(타이머 화면)과 횟수·세트형 운동(세트 입력 화면) 모두 동일하게 동작한다.
7. 이렇게 추가한 링크는 홈 화면의 운동 수정 모달에서도 그대로 보이고, 거기서 다시 수정·삭제할 수 있다 — 기존 기능과 같은 데이터를 공유한다.

## 요구사항

1. 자세 안내 영상 링크가 없는 운동의 측정 화면에는 "자세 영상 보기" 버튼 대신 "자세 영상 링크 추가" 버튼이 보인다.
2. "자세 영상 링크 추가" 버튼을 탭하면 유튜브 링크 입력란과 저장·취소 버튼이 그 자리에 펼쳐진다.
3. 입력한 링크가 유튜브 URL 형식(watch?v=, youtu.be/, shorts/)이 아니면 저장이 거부되고 안내 메시지가 표시된다 (기존 "운동 자세 안내 영상" 기능의 검증 규칙과 동일하게 적용한다).
4. 저장에 성공하면 그 운동에 링크가 실제로 저장되고, 같은 화면이 곧바로 기존의 "자세 영상 보기" 토글 버튼으로 전환되어 즉시 펼쳐 재생할 수 있다 (화면 재진입 불필요).
5. 취소를 누르면 입력 내용은 버려지고 "자세 영상 링크 추가" 버튼 상태로 되돌아간다.
6. 시간형 운동의 측정 화면(TimerScreen)과 횟수·세트형 운동의 측정 화면(RepsScreen) 모두에서 동일하게 동작한다.
7. 이 방법으로 등록한 링크는 홈 화면의 운동 수정 모달에서도 동일하게 보이고 수정·삭제할 수 있다 — 별도의 저장소를 쓰지 않는다.
8. 이미 링크가 등록된 운동의 측정 화면 동작(토글·재생)은 기존과 동일하게 유지된다 — 이번 기능은 "링크 없음" 상태에만 추가된다.

## 제외 범위

- 측정 화면에서 이미 등록된 링크를 수정·삭제하는 기능 — 그건 기존처럼 운동 수정 모달에서만 가능하다 (이번엔 "추가"만 다룬다).
- 측정 중(카운트다운·타이머 진행 중, 세트 입력 중)에도 링크 추가 버튼을 계속 노출할지 여부 — 필요하면 /design에서 화면 단계별 노출 조건을 정한다.
- 새로운 유튜브 링크 검증 규칙 도입 — 기존 검증 로직을 그대로 재사용한다.
- 새로 필요해지는 문구(버튼 라벨, 입력란 placeholder 등)의 번역 방식 논의 — 기존 4개 언어(한국어/영어/일본어/중국어) 번역 체계에 맞춰 추가하되, 세부 문구는 /dev 단계에서 정한다.

## 성공 기준

- [ ] `npx tsc --noEmit` 타입 체크 통과
- [ ] 링크가 없는 운동의 측정 화면에 "자세 영상 링크 추가" 버튼이 보인다 (타이머 화면, 세트 입력 화면 모두)
- [ ] 버튼을 탭하면 입력란과 저장·취소 버튼이 펼쳐진다
- [ ] 유튜브 URL 형식이 아닌 값을 저장하려 하면 거부되고 안내 메시지가 보인다
- [ ] 유효한 링크를 저장하면 그 운동에 실제로 저장되고, 화면이 즉시 "자세 영상 보기" 토글 버튼으로 바뀐다
- [ ] 바뀐 토글 버튼을 눌러 화면 재진입 없이 바로 영상을 재생할 수 있다
- [ ] 취소를 누르면 입력 내용이 버려지고 원래 버튼 상태로 돌아간다
- [ ] 이렇게 추가한 링크가 홈 화면의 운동 수정 모달에도 동일하게 반영돼 있다
- [ ] 이미 링크가 있던 운동의 기존 재생 동작은 변화 없이 그대로 유지된다
- [ ] 새로 추가된 문구가 4개 언어(한국어/영어/일본어/중국어) 모두에 번역되어 있다

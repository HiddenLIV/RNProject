# 테마 컬러 커스터마이징

## 목적

지금은 앱의 포인트 컬러(현재 다크+마젠타 팔레트)가 코드에 고정돼 있어 모든 사용자가 같은 색을 본다. 사용자가 자신의 취향에 맞는 포인트 컬러를 직접 골라 앱 전체에 즉시 반영할 수 있게 하여 개인화를 제공한다. (앱 아이콘 색상 변경은 이번 범위에서 제외한다.)

## 사용자 시나리오

1. 홈 화면 상단, 제목("나의 운동 일지") 옆에 원형 컬러 스와치 5개가 가로로 나란히 배치돼 있다: 기본(마젠타), 오렌지, 민트, 레드, 블루.
2. 현재 적용 중인 색의 스와치에는 선택 표시(테두리/체크 등)가 있어 지금 어떤 색이 적용돼 있는지 바로 알 수 있다.
3. 사용자가 다른 스와치를 탭하면 별도 확인 절차 없이 즉시 그 색이 앱 전체(포인트 컬러가 쓰이던 모든 화면: 홈, 운동 추가/수정, 매달리기 타이머, 기록 목록 등)에 반영된다.
4. 앱을 껐다 다시 켜도 마지막으로 고른 색이 그대로 유지된다.
5. 배경, 카드, 텍스트 등 다크 톤 베이스와 경고(삭제 등) 색상은 어떤 포인트 컬러를 고르든 바뀌지 않는다 — 바뀌는 건 포인트 컬러 계열뿐이다.
6. 앱 아이콘은 어떤 색을 골라도 바뀌지 않는다.

## 요구사항

1. 홈 화면 상단 제목 영역 옆에 원형(round) 컬러 스와치 5개가 가로로 배치되어 표시된다:

   | 프리셋 | 색 이름 | HEX |
   |---|---|---|
   | 기본 | 다크 마젠타 (현재 색) | `#9B2791` |
   | 오렌지 | Strava 오렌지 | `#FC4C02` |
   | 민트 | Whoop 민트 | `#00D9A3` |
   | 레드 | Peloton 레드 | `#E62B2B` |
   | 블루 | MyFitnessPal 블루 | `#0072CE` |

2. 현재 선택된 프리셋의 스와치는 시각적으로 구분되는 선택 표시(예: 테두리 강조)가 있다.
3. 스와치를 탭하면 확인 팝업 없이 즉시 해당 프리셋이 적용된다.
4. 프리셋을 바꾸면 포인트 컬러 롤(primary/primaryPressed/primarySoft/accent/accentSoft 및 이를 참조하는 버튼·아이콘·강조 요소 등)이 선택한 프리셋 색으로 전체 화면에서 일관되게 바뀐다 — 홈, 운동 추가/수정 화면, 매달리기 타이머, 기록 목록 등 포인트 컬러가 쓰이는 모든 곳에 반영된다.
5. 배경(background), 카드(card/cardMuted), 텍스트(text/textMuted/textFaint), 경고색(danger, `#FF453A`) 등 다크 베이스 색상은 프리셋 변경과 무관하게 항상 고정이다. 레드 프리셋(`#E62B2B`)은 경고색과 계열이 가깝지만, 삭제·경고 버튼 등은 항상 고정된 danger 색을 쓰므로 프리셋과 실제로 혼동되진 않는다 (의도된 결과로 별도 조치 불필요).
6. 선택한 프리셋은 기기에 저장되어, 앱을 재시작해도 마지막 선택이 그대로 유지된다.
7. 앱을 처음 설치했을 때 기본값은 지금의 마젠타 계열 색(`#9B2791`)이다.
8. 앱 아이콘(홈 화면 런처 아이콘) 색상은 이번 기능으로 변경되지 않는다.

## 제외 범위

- 앱 아이콘 색상 변경 (이번엔 다루지 않음 — 사용자 요청으로 명시적 제외)
- 라이트 모드 등 배경·카드까지 포함한 전체 팔레트 전환
- 사용자가 임의의 색(컬러피커/HEX 직접 입력)을 지정하는 기능 — 이번엔 미리 정한 5가지 프리셋 중 선택만 지원
- 6개 이상의 추가 프리셋, 프리셋 직접 추가/편집 기능
- 별도의 "설정" 화면 신설 — 진입은 홈 화면 상단 스와치로 충분
- 여러 기기 간 테마 설정 동기화(클라우드 동기화)

## 성공 기준

- [ ] `npx tsc --noEmit` 타입 체크 통과
- [ ] 홈 화면 제목 옆에 원형 컬러 스와치 5개(기본·오렌지·민트·레드·블루, 위 표의 HEX 값대로)가 가로로 보인다
- [ ] 현재 적용된 프리셋의 스와치가 시각적으로 구분되어 표시된다
- [ ] 스와치를 탭하면 확인 절차 없이 즉시 앱 전체의 포인트 컬러가 바뀐다
- [ ] 홈, 운동 추가/수정, 매달리기 타이머, 기록 목록 등 포인트 컬러를 쓰던 화면 모두에서 새 색이 일관되게 반영된다
- [ ] 배경·카드·텍스트·경고색은 프리셋을 바꿔도 변하지 않는다
- [ ] 앱을 재시작해도 마지막으로 고른 프리셋이 유지된다
- [ ] 최초 설치 시 기본값은 현재의 마젠타 계열 색이다
- [ ] 앱 아이콘 색상은 프리셋을 바꿔도 변하지 않는다

# Phase 2-1 사용자 요청 사항

> `docs/roadmap.md`의 "Phase 2-1 — 사용자 요청 사항" 체크리스트(95~106행) 9개 항목을 다룬다. 각 요구사항 그룹 번호(1~9)는 그 체크리스트 항목 순서와 1:1로 대응한다.

## 목적

실사용자가 앱을 써보고 준 피드백 9건을 반영해, 측정 화면(무게·횟수)·설정·달력에서 겪은 구체적인 불편과 버그를 해결한다. 새 기능을 넓히기보다 이미 있는 화면을 사용자가 실제로 걸린 지점 위주로 다듬는 것이 목적이다.

## 사용자 시나리오

1. 헬스장처럼 조용한 곳에서도, 시끄러운 곳에서도 알림음이 원하는 크기로 들리길 바라는 사용자가 설정 화면에서 알림음 볼륨을 "기기 볼륨 따라가기" 또는 "최대"로 고른다.
2. 진동이 부담스러운 상황(도서관, 취침 전 등)의 사용자가 설정에서 진동을 꺼두면, 이후 버튼을 눌러도 진동 없이 화면 하이라이트로만 눌림을 확인한다.
3. 활동 기록 화면에서 오늘 날짜를 눌렀을 때 날짜 숫자가 사라지지 않고 항상 보인다.
4. 무게·횟수 측정 화면에서 지금 몇 번째 세트를 입력하는 중인지 라벨만 보고 바로 안다.
5. 방금 잘못 입력한 세트를 발견한 사용자가 그 세트 행을 눌러 값을 고치고 체크 버튼으로 확정한다 — 새 세트로 중복 추가되지 않는다.
6. 세트를 몇 개 기록해두고 저장을 깜빡한 채 뒤로가기를 누르면, 저장할지 물어보는 alert가 떠서 실수로 기록을 날리지 않는다.
7. 휴식 타이머가 필요 없는 사용자는 기본값(꺼짐)을 그대로 두면 휴식 관련 UI 자체가 화면에 나타나지 않고, 필요할 때만 켜서 쓴다.
8. 무게·횟수 측정 중 휴식이 끝나면 복싱 라운드 종료를 연상시키는 벨 소리가 울려, 기존 벨소리와 구분되는 신호로 인지한다.
9. 휴식을 기다리는 동안 심심하지 않게 동기부여 문구가 함께 보인다.

## 요구사항

### 1. 알림음 볼륨 설정 (Android 전용)

1-1. 설정 화면에 "알림음 볼륨" 항목이 추가된다. 대상은 (a) 시간형 운동 측정 화면(TimerScreen)의 벨 간격 알림음, (b) 무게·횟수 측정 화면(RepsScreen)의 세트 간 휴식 타이머 종료 알림음이며, 두 사운드는 하나의 설정값을 공유한다.
1-2. 값은 "기기 볼륨 따라가기"(기본값)와 "최대" 두 단계다.
1-3. 이 설정 항목은 Android에서만 노출된다. iOS 빌드에는 보이지 않는다 — iOS는 OS 정책상 앱이 시스템 볼륨 자체를 사용자 조작 없이 바꿀 수 없어, 이미 최대 상대음량으로 재생 중인 지금과 새 옵션이 체감상 구분되지 않기 때문이다.
1-4. Android에서 "최대"를 선택하면, 위 두 알림음이 울리는 순간 시스템 미디어 볼륨을 최대로 일시적으로 올려 재생하고, 재생이 끝나면 사용자가 원래 맞춰둔 시스템 볼륨으로 되돌린다.
1-5. "기기 볼륨 따라가기"에서는 지금과 동일하게 시스템 볼륨을 건드리지 않고 재생한다.
1-6. 설정값은 기기에 저장되어 앱을 재시작해도 유지된다.
1-7. 새 설정 라벨과 두 선택지 문구는 4개 언어(ko/en/ja/zh) 모두 번역되어 표시된다.

### 2. 진동 유무 설정 (앱 전체 단일 토글)

2-1. 설정 화면에 "진동" on/off 토글이 추가된다. 기본값은 켜짐(기존 동작과 동일).
2-2. 토글을 끄면, 현재 진동이 걸려 있는 아래 항목 전부에서 진동이 울리지 않는다.
   - 버튼(누르는 즉시 진동): 카운트다운·벨 간격·휴식 시간·이번 세트 횟수 스테퍼의 증감 버튼, 홈 화면 "운동 추가" FAB, 휴식 건너뛰기 버튼, 세트 추가 버튼, 세트 삭제 버튼, 측정 취소·정지·다시 측정·시작 버튼
   - 자동 이벤트(결과로 울림): 세트 저장 완료, 휴식 타이머 종료
2-3. 진동이 꺼진 상태에서 위 버튼들을 누르면, 눌림을 알 수 있는 시각적 하이라이트(눌림 시 색상/투명도 변화) 효과가 나타난다.
2-4. 설정값은 기기에 저장되어 앱을 재시작해도 유지된다.
2-5. 새 토글 라벨은 4개 언어 모두 번역되어 표시된다.

### 3. 캘린더 당일 선택 시 날짜 안 보이는 현상 수정

3-1. 활동 기록 화면의 캘린더에서 오늘 날짜를 선택(탭)했을 때, 날짜 숫자가 배경에 묻히지 않고 항상 눈에 보인다.
3-2. 오늘이 아닌 날짜를 선택했을 때도 동일하게 숫자가 항상 보인다.
3-3. 라이트/다크 모드와 강조색 프리셋을 바꿔가며 확인해도 선택된 날짜의 숫자가 항상 보인다.

### 4. "이번 세트" 라벨에 세트 번호 표시

4-1. 무게·횟수 측정 화면의 "이번 세트" 섹션 라벨에 다음에 추가될 세트 번호가 함께 표시된다(예: "이번 세트: 2세트"). 번호는 현재까지 기록된 세트 수 + 1이다.
4-2. 세트가 하나도 없는 최초 상태에서는 번호가 1로 보인다.
4-3. 세트를 추가하면 번호가 1 늘어나고, 세트를 삭제하면 그 시점의 "기록된 세트 수 + 1"로 다시 계산된다.
4-4. 번호 표기 방식은 기존 기록된 세트 목록에 이미 쓰이고 있는 "N세트" 번역 패턴(`t.reps.setNumberLabel`)과 일관되게 4개 언어 모두 자연스럽게 표시된다.

### 5. 기록된 세트 수정 기능

5-1. "이미 기록된 세트" 목록에서 세트 하나를 누르면 그 세트가 수정 모드로 전환된다 — 무게·횟수 입력 칸에 그 세트의 기존 값이 채워지고, 세트 추가(+) 아이콘 버튼이 확인(체크) 아이콘으로 바뀐다.
5-2. 수정 모드에서 체크 버튼을 누르면 입력 칸의 새 값으로 그 세트가 원래 순서(인덱스) 그대로 갱신된다 — 새 세트로 추가되지 않고 총 세트 개수도 바뀌지 않는다. 이후 입력 칸과 추가 버튼은 "다음 세트 입력" 상태로 돌아간다.
5-3. 한 번에 하나의 세트만 수정 대상이 된다 — 수정 중 다른 세트 행을 누르면 수정 대상과 입력 칸 값이 그 세트로 교체된다.
5-4. 수정 모드에 들어가거나 값을 확정해도 진행 중인 휴식 타이머에는 영향이 없다(그대로 계속 진행).

### 6. 저장 안 하고 뒤로가기 시 확인 alert

6-1. 무게·횟수 측정 화면에서 기록된 세트가 1개 이상 있고 "저장" 버튼을 아직 누르지 않은 상태로, 운동 화면의 뒤로가기(헤더 뒤로가기 버튼 또는 하드웨어/제스처 뒤로가기)를 실행하면 저장 여부를 묻는 alert가 뜬다.
6-2. alert에는 "저장"과 "저장 안 함" 두 선택지가 있다.
6-3. "저장"을 선택하면 지금까지 기록된 세트를 기존 저장 버튼과 같은 로직으로 저장한 뒤 뒤로 이동한다.
6-4. "저장 안 함"을 선택하면 기록된 세트를 저장하지 않고 그대로 뒤로 이동한다.
6-5. 기록된 세트가 0개인 상태에서 뒤로가기를 실행하면 지금처럼 alert 없이 바로 뒤로 이동한다.
6-6. 휴식 타이머 진행 여부는 이 alert가 뜨는 조건에 영향을 주지 않는다(기록된 세트 개수만으로 판단한다).

### 7. 휴식 타이머 기본값 off + off일 때 화면 숨김

7-1. 저장된 설정이 없는 운동(신규 등록 운동 포함)의 휴식 타이머 기본값은 꺼짐이다. 이미 사용자가 설정을 저장해 둔 기존 운동의 값은 그대로 유지된다(소급 변경하지 않음).
7-2. 휴식 타이머가 꺼짐 상태일 때는 무게·횟수 측정 화면에 휴식 시간(초) 스테퍼가 보이지 않는다 — 휴식 타이머를 켜는 스위치만 보인다.
7-3. 휴식 타이머를 켜짐으로 바꾸면 휴식 시간 스테퍼가 다시 보이고, 세트 추가 시 휴식 카운트다운이 기존처럼 자동 시작된다.
7-4. 꺼짐 상태에서 세트를 추가해도 휴식 카운트다운은 시작되지 않는다(기존 "세트 간 휴식 타이머" 요구사항과 동일하게 유지).
7-5. 켜짐/꺼짐 상태는 운동별로 저장되어, 같은 운동을 다시 열어도 유지된다.

### 8. 휴식 타이머 종료음을 복싱 벨 소리로 변경

8-1. 무게·횟수 측정 화면에서 휴식 타이머가 0에 도달했을 때 울리는 알림음이 복싱 경기 라운드 종료를 연상시키는 벨 소리로 바뀐다.
8-2. 시간형 운동(TimerScreen)의 벨 간격 알림음은 이번 변경 대상이 아니다 — 기존 사운드를 그대로 유지한다.
8-3. 새 사운드는 기존 생성형 에셋 관행에 따라 `scripts/`의 생성 스크립트로 만들어져, 필요 시 스크립트로 재생성할 수 있다.

### 9. 휴식 중 동기부여 문구 표시

9-1. 휴식 타이머가 진행 중인 동안, 휴식 배너에 동기부여 문구가 함께 표시된다.
9-2. 문구는 기존 측정 중 화면(TimerScreen)이 쓰는 동기부여 문구 목록(`t.quotes`)과 같은 방식(3초마다 교체, 직전 문구 반복 없음)으로 동작한다.
9-3. 휴식이 끝나거나(0 도달/건너뛰기) 중단되면 문구 표시도 함께 사라진다.
9-4. 문구는 이미 4개 언어로 준비된 `t.quotes` 목록을 그대로 사용한다.

## 제외 범위

- iOS에서 알림음 "최대" 옵션 노출 — Android에서만 이 설정을 보여준다
- 알림음 볼륨을 3단계 이상 또는 슬라이더로 세분화하는 것 — 이번엔 2단계(기기 볼륨 따라가기/최대)만
- 진동 세기(강/중/약) 조절이나 버튼별 개별 진동 on/off — 이번엔 앱 전체 단일 켜짐/꺼짐 토글만
- 캘린더의 다른 기능 변경(월 이동, 연월 선택, 점 표시 등은 기존 그대로 유지) — 이번엔 선택 시 숫자가 안 보이는 버그만 수정
- 세트 수정 시 무게·횟수 외의 값(촬영 영상 재첨부 등) 변경 — 수정 대상은 무게·횟수 값뿐
- 세트 수정 모드를 값 변경 없이 취소하는 전용 버튼 — 다른 세트를 다시 선택하거나 원래 값을 그대로 입력해 확정하는 방식으로만 빠져나올 수 있다
- "측정" 탭에서 "기록" 탭으로 전환할 때의 미저장 경고 — 이번엔 뒤로가기(화면 이탈)에만 적용하고, 탭 전환 시 미저장 세트가 사라지는 기존 동작은 이번 범위에서 다루지 않는다
- 복싱 벨 사운드를 여러 종류 중 사용자가 고르게 하는 기능 — 이번엔 고정된 사운드 하나로 교체
- 휴식 전용 동기부여 문구를 새로 작성하는 것 — 기존 `t.quotes` 목록을 그대로 재사용
- 휴식 타이머 켜짐/꺼짐을 바꿨을 때 이미 진행 중인 휴식이나 이미 기록된 세트를 소급 처리하는 것 — 상태 전환은 그다음 세트부터 적용

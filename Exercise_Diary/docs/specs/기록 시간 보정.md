# 기록 시간 보정

## 목적

정지 버튼을 누르는 시점은 사용자의 반응 속도·손 위치 이동 시간 때문에 실제로 봉에서 내려온 순간과 오차가 생긴다. 정지 직후 결과 화면에서 1초 단위로 값을 조정할 수 있게 하여, 저장되는 기록이 실제 버틴 시간에 더 가깝도록 한다.

## 사용자 시나리오

1. 사용자가 측정 중 정지 버튼을 눌러 측정이 종료된다. 1초 이상이면 그 즉시 기록이 저장된다(기존 동작과 동일).
2. 결과 화면에 측정된 시간(예: 34.27초)과 함께 `−1초` / `+1초` 보정 버튼이 표시된다.
3. 사용자가 필요한 만큼 `−1초` 또는 `+1초`를 눌러 정수초 부분만 조정한다 (소수점 이하는 유지). 예: 34.27초 → `−1초` → 33.27초. 보정할 때마다 그 값으로 저장된 기록도 함께 갱신된다 — 별도의 저장 버튼이나 확인 절차 없이, 결과 화면에 보이는 값이 항상 곧 저장된 값이다.
4. 기록 탭으로 이동하면 방금 측정·보정한 기록이 목록에 있는 것을 바로 확인할 수 있다.
5. 다시 시작·메인으로·탭 이동 등 어떤 방식으로 결과 화면을 벗어나도 마지막으로 보정한 값이 그대로 남아있다.

## 요구사항

1. 결과 화면에 측정된 시간 옆(또는 아래)에 `−1초`, `+1초` 두 개의 보정 버튼이 표시된다.
2. `+1초`를 누르면 현재 표시된 시간의 정수초 부분에 1을 더한다. 소수점 이하 값은 그대로 유지된다 (예: 34.27초 → 35.27초).
3. `−1초`를 누르면 정수초 부분에서 1을 뺀다. 소수점 이하 값은 그대로 유지된다 (예: 34.27초 → 33.27초).
4. 보정된 값이 0초 미만이 되지 않도록 제한한다 — 정수초 부분이 0일 때 `−1초` 버튼은 비활성화된다.
5. `+1초`는 별도 상한 없이 계속 누를 수 있다.
6. 보정 버튼을 누르는 즉시 화면에 표시된 값이 갱신된다.
7. "1초 미만 기록은 저장하지 않는다" 규칙은 보정 후 최종 값 기준으로, 그것도 실시간으로 적용된다 — 정지 시점에 0.8초라 저장되지 않았어도 `+1초` 보정으로 1.8초가 되는 순간 저장되고, 반대로 저장된 상태에서 `−1초`로 다시 1초 미만이 되면 그 기록은 삭제된다.
8. 정지해서 1초 이상이면 그 즉시 기록이 저장되고, 이후 보정(±1초)은 별도 확인 없이 그 기록을 계속 갱신한다 — "저장" 시점을 사용자가 따로 신경 쓸 필요가 없다.
9. 다시 시작 버튼으로 새 측정을 시작하면 보정 상태는 초기화되고, 새 측정 결과에 대해 다시 −1초/+1초부터 보정할 수 있다.

## 제외 범위

- 이미 저장된 과거 기록(기록 목록)의 사후 수정 — 이번에는 정지 직후 결과 화면에서만 가능
- 1초 미만 단위(0.1초, 0.01초)의 정밀 보정 — 이번에는 정수초 단위만
- 보정 횟수 제한, 보정 이력 표시("N초 보정됨" 등) — 이번에는 다루지 않음
- ±5초 등 보정 상한 — 이번에는 0초 미만 제한만 둔다
- 명시적 "저장하기" 버튼 — 처음엔 사용자 요청으로 추가했으나, 정지·보정이 항상 즉시 저장되는 구조로 바뀌면서 버튼이 할 일이 없어져 제거했다 (2026-07-19)

## 성공 기준

- [ ] `npx tsc --noEmit` 타입 체크 통과
- [ ] 정지 후 결과 화면에 `−1초`, `+1초` 버튼이 표시된다
- [ ] `+1초`를 누르면 정수초 부분만 1 증가하고 소수점 이하는 유지된다 (예: 34.27 → 35.27)
- [ ] `−1초`를 누르면 정수초 부분만 1 감소하고 소수점 이하는 유지된다 (예: 34.27 → 33.27)
- [ ] 정수초 부분이 0일 때 `−1초` 버튼이 비활성화되어 더 내려가지 않는다
- [ ] `+1초`는 반복해서 눌러도 제한 없이 계속 증가한다
- [ ] 버튼을 누르면 화면 표시값이 즉시 갱신된다
- [ ] 정지 즉시(저장 버튼 없이) 1초 이상 결과가 기록 목록에 나타난다
- [ ] 1초 미만 결과를 `+1초`로 1초 이상으로 올리면, 저장 버튼 없이도 기록 목록에 나타난다
- [ ] 1초 이상 결과를 `−1초`로 1초 미만으로 내리면, 기록 목록에서 사라진다
- [ ] 다시 시작 버튼으로 새 측정을 시작하면 보정 상태가 초기화된다
- [ ] 앱을 강제 종료했다 다시 열어도 마지막으로 보정한 값이 기록에 남아있다

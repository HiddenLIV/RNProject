# 홈 화면 주간 PR 카운트 볼륨 기준 반영

## 목적

`docs/specs/무게 있는 운동 최고 기록 볼륨 기준 변경.md`에서 기록 화면의 "최고 기록" 판정을 무게 있는 운동에 한해 볼륨(무게×횟수 합) 기준으로 바꿨지만, 홈 화면의 "이번 주 PR N회 경신" 카운트(`src/lib/stats.ts`)는 여전히 총 횟수만으로 PR 이벤트를 판정한다. 그 결과 기록 화면에서는 "최고 기록"으로 표시되는 기록이 홈 화면 PR 카운트에는 잡히지 않는 등 두 화면이 같은 기록을 서로 다른 기준으로 판단하는 불일치가 있다. 무게 있는 운동에 한해 PR 이벤트 판정 기준도 볼륨으로 맞춰 두 화면의 기준을 일치시킨다.

## 사용자 시나리오

1. 무게 있는 운동에서 "10kg×20회"(볼륨 200)를 기록한 뒤, 이어서 "20kg×15회"(볼륨 300, 횟수는 더 적음)를 기록한다.
2. 기록 화면에서 두 번째 기록이 "최고 기록"으로 표시되는 것과 마찬가지로, 홈 화면의 이번 주 PR 카운트에도 이 기록이 PR 이벤트로 반영되어 있다.
3. 무게를 기록하지 않는 운동(턱걸이·팔굽혀펴기 등)은 기존과 동일하게 총 횟수 기준으로 PR 이벤트가 판정된다 — 이번 변경의 영향을 받지 않는다.

## 요구사항

1. `src/lib/stats.ts`에서 무게 있는 운동(`exercise.usesWeight === true`)의 PR 이벤트 판정 기준을 "세트별 횟수 합"에서 "세트별 (무게×횟수)의 합(볼륨)"으로 변경한다. 이는 `docs/design/무게 있는 운동 최고 기록 볼륨 기준 변경.md`에서 `bestRepsRecord`가 사용하는 것과 동일한 판정 기준이어야 한다.
2. 무게 없는 운동은 기존 로직(횟수 합 비교)을 그대로 유지한다 — 동작 변화가 없어야 한다.
3. 서로 다른 무게 단위(kg/lb)로 저장된 기록끼리 볼륨을 비교할 때는 `bestRepsRecord`와 동일하게 kg으로 환산한 뒤 비교한다 — 판정 기준이 화면마다 다르게 구현되지 않도록, 가능하면 `records.ts`의 기존 환산 로직을 재사용한다.
4. 무게 값이 없는 세트는 0으로 취급한다(기존 `totalVolume`과 동일한 규칙).
5. `weeklyPrCount`(이번 주 PR 이벤트 수), `weeklyActiveDays`, `weeklyCountsByExerciseId`, `recordedDates` 등 PR 판정과 무관한 다른 통계 값의 계산 방식은 변경하지 않는다.
6. 시간형 운동(`measureType === 'time'`)의 PR 판정(기존 `durationMs` 기준)은 이번 변경의 영향을 받지 않는다.

## 제외 범위

- 홈 화면에 "이 PR은 볼륨 기준입니다" 같은 별도 설명 문구나 볼륨 수치 자체를 새로 노출하는 UI 변경은 하지 않는다 — "PR N회 경신" 문구와 표시 형태는 그대로 두고 판정 기준만 바꾼다.
- 추정 1RM 등 다른 강도 지표 도입은 하지 않는다.
- 기존에 저장된 기록 데이터의 마이그레이션이나 재계산 저장은 하지 않는다 — PR 카운트는 항상 조회 시점에 동적으로 계산된다(기존 방식과 동일).
- 캘린더 히트맵, 스트릭 등 PR 카운트 외의 다른 홈 화면 통계 로직 변경은 하지 않는다.

## 성공 기준

- [ ] 무게 있는 운동에서 횟수는 적지만 볼륨이 큰 기록이 PR 이벤트로 카운트된다.
- [ ] 무게 있는 운동에서 횟수는 많지만 볼륨이 작은 기록은 PR 이벤트로 카운트되지 않는다.
- [ ] 무게 없는 운동의 PR 카운트 결과가 이번 변경 전후로 동일하다(회귀 없음).
- [ ] 시간형 운동의 PR 카운트 결과가 이번 변경 전후로 동일하다(회귀 없음).
- [ ] 무게 값이 없는 세트가 포함된 기록도 정상적으로 PR 판정 대상에 포함되고, 해당 세트의 무게는 0으로 계산된다.
- [ ] kg 단위 기록과 lb 단위 기록이 섞여 있어도 환산 후 올바르게 PR 이벤트가 판정된다.
- [ ] 동일한 기록 데이터에 대해 기록 화면의 "최고 기록" 판정과 홈 화면의 PR 이벤트 판정 결과가 서로 모순되지 않는다(둘 다 최고/PR로 인정하거나, 둘 다 아니거나).
- [ ] `npx tsc --noEmit`, `npm test` 통과.

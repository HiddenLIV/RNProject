# 앱 사용법 안내

## 목적

처음 앱을 쓰는 사용자는 운동 추가·측정·기록·촬영 등 여러 기능이 한 화면(홈)에 몰려 있어 어디서부터 시작해야 할지 헷갈릴 수 있다. 홈 화면에서 언제든 열어볼 수 있는 도움말을 둬서, 필요할 때 앱의 핵심 기능을 훑어볼 수 있게 한다.

## 사용자 시나리오

1. 홈 화면("나의 운동 일지") 우측 상단에 도움말 버튼이 있다.
2. 버튼을 누르면 도움말 화면이 열린다.
3. 화면에는 앱의 핵심 기능(운동 추가, 측정 시작, 기록 확인, 운동 촬영, 자세 안내 영상, 운동 커스터마이징)이 섹션별로 나열돼 있고, 각 섹션은 아이콘·일러스트와 짧은 설명 텍스트로 구성된다.
4. 스크롤해서 모든 섹션을 위아래로 훑어볼 수 있다.
5. 닫기 버튼(또는 기기 뒤로가기)을 누르면 홈 화면으로 돌아간다.
6. 도움말은 이 버튼을 눌렀을 때만 나타난다 — 앱을 처음 설치해 실행해도 자동으로 뜨지 않는다.

## 요구사항

1. 홈 화면 우측 상단에 도움말 버튼이 항상 보인다.
2. 버튼을 누르면 도움말 화면(또는 모달)이 열린다.
3. 도움말 화면은 다음 6가지 핵심 기능을 각각 하나의 섹션으로 설명한다: 운동 추가, 측정 시작(타이머/횟수·세트), 기록 확인, 운동 촬영, 자세 안내 영상, 운동 커스터마이징(이름·자세 영상 링크 수정, 삭제 — 아이콘 변경은 운동 추가 시점에만 가능하고 수정 화면엔 없음).
4. 각 섹션은 그 기능을 나타내는 아이콘·일러스트 하나와, 어떻게 쓰는지 설명하는 짧은 텍스트로 구성된다. 실제 앱 스크린샷은 쓰지 않는다.
5. 섹션이 화면 하나에 다 안 들어가면 스크롤해서 모든 섹션을 볼 수 있다.
6. 닫기 버튼을 누르거나 기기 뒤로가기를 하면 홈 화면으로 돌아간다.
7. 앱을 처음 설치해 실행했을 때 이 도움말이 자동으로 뜨지 않는다 — 사용자가 버튼을 눌러야만 열린다.

## 제외 범위

- 실제 앱 스크린샷 캡처·삽입 — 아이콘·일러스트로 대체한다.
- 스와이프로 넘기는 단계별 온보딩 캐러셀 — 한 화면에서 스크롤로 전체를 보여준다.
- 다국어 지원.
- 도움말 내 검색 기능.
- 동영상 형태의 튜토리얼.
- 최초 실행 시 자동으로 뜨는 온보딩 흐름 — 이번 기능은 버튼을 눌렀을 때만 여는 온디맨드 도움말만 다룬다.

## 성공 기준

- [ ] `npx tsc --noEmit` 타입 체크 통과
- [ ] 홈 화면 우측 상단에 도움말 버튼이 보인다
- [ ] 버튼을 누르면 도움말 화면이 열린다
- [ ] 운동 추가·측정 시작·기록 확인·운동 촬영·자세 안내 영상·운동 커스터마이징 6개 섹션이 모두 있다
- [ ] 각 섹션에 아이콘·일러스트와 설명 텍스트가 함께 표시된다
- [ ] 섹션이 많아 화면을 넘어가도 스크롤로 전부 볼 수 있다
- [ ] 닫기 버튼 또는 기기 뒤로가기로 홈 화면에 돌아갈 수 있다
- [ ] 앱을 처음 실행해도 도움말이 자동으로 뜨지 않는다

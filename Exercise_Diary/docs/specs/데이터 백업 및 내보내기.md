# 데이터 백업 및 내보내기

## 목적

앱의 모든 데이터(운동 목록, 측정 기록, 설정, 테마)는 기기 로컬 저장소(AsyncStorage)에만 존재한다. 기기 변경, 재설치, 앱 삭제, 패키지명 변경 등이 발생하면 그동안 쌓아온 운동 기록이 전부 영구적으로 사라진다. 사용자가 원하는 시점에 데이터를 파일로 내보내 안전한 곳에 보관하고, 필요할 때 그 파일로 복원할 수 있게 하여 데이터 유실 위험을 없앤다.

## 사용자 시나리오

**내보내기**
1. 홈 화면 상단(현재 도움말 `?` 아이콘 옆)에 백업 아이콘이 추가되어 있다.
2. 아이콘을 탭하면 백업 모달이 뜨고, "내보내기"와 "가져오기" 두 메뉴가 보인다.
3. "내보내기"를 선택하면 앱에 저장된 모든 데이터를 하나의 백업 파일로 만들고, OS의 공유 시트(카카오톡, 이메일, 드라이브 앱, 파일 앱 등)를 띄워 사용자가 원하는 곳에 저장하거나 전송할 수 있게 한다.
4. 내보내기가 끝나면 별도 처리 없이 공유 시트가 닫히는 것으로 종료된다(성공/실패 토스트 정도만 표시).

**가져오기(복원)**
1. 같은 백업 모달에서 "가져오기"를 선택하면 기기의 파일 선택 화면이 뜬다.
2. 이 앱이 만든 백업 파일을 선택하면, 적용 전에 "현재 기기의 모든 운동 데이터가 백업 파일 내용으로 대체됩니다"라는 경고와 함께 확인/취소를 묻는다.
3. 사용자가 확인하면 현재 기기의 데이터를 백업 파일 내용으로 전체 교체(덮어쓰기)하고, 완료 메시지를 보여준 뒤 홈 화면에 최신 상태가 바로 반영된다.
4. 형식이 맞지 않거나 손상된 파일을 선택한 경우, 기존 데이터는 전혀 건드리지 않고 실패 이유를 알 수 있는 오류 메시지를 보여준다.

## 요구사항

1. 홈 화면 상단 아이콘 영역(기존 도움말 아이콘 옆)에 백업 진입 아이콘이 추가된다.
2. 아이콘을 탭하면 "내보내기" / "가져오기" 두 가지 동작을 고를 수 있는 화면(모달)이 뜬다.
3. 내보내기는 다음 데이터를 빠짐없이 하나의 파일에 포함한다: 운동 목록(이름·아이콘·측정 방식·무게 사용 여부 등 모든 속성), 운동별 측정 기록(시간형 기록·횟수형 기록 전부, 삭제되지 않은 것 전체), 운동별 타이머 설정(준비 카운트다운·벨 간격), 현재 테마(포인트 컬러) 설정.
4. 내보낸 파일에는 이후 형식이 바뀌어도 이전 백업을 구분할 수 있도록 앱 버전 또는 백업 형식 버전과, 내보낸 일시가 함께 기록된다.
5. 내보낸 파일은 OS 공유 시트를 통해 전달되며, 사용자가 저장 위치(로컬 파일, 클라우드 앱, 메신저 등)를 자유롭게 고를 수 있다.
6. 측정 기록에 첨부된 자세 촬영 영상(`videoRef`)은 영상 파일 자체가 아니라 기기 갤러리 참조 ID이므로, 백업 파일에는 그 참조 값만 포함되고 영상 파일 자체는 포함되지 않는다 (요구사항 8의 제약과 연결).
7. 가져오기는 이 앱이 만든 백업 파일만 유효한 것으로 인식하며, 파일 형식이 다르거나 손상된 경우 명확한 오류 메시지를 보여주고 기존 데이터는 전혀 변경하지 않는다.
8. 가져오기를 실제로 적용하기 전, 사용자에게 "현재 데이터가 백업 파일 내용으로 전부 대체된다"는 사실을 알리는 확인 절차가 있다. 확인 전에는 아무 데이터도 바뀌지 않는다.
9. 가져오기를 확인하면 현재 기기의 운동 목록·기록·설정·테마가 백업 파일 내용으로 전체 교체(기존 데이터와의 병합이 아님)된다.
10. 가져오기가 끝나면 별도로 앱을 재시작하지 않아도 홈 화면 등 화면에 복원된 데이터가 바로 보인다.
11. 백업/가져오기 과정 중 사용자가 취소하면 아무 부작용 없이 원래 화면으로 돌아간다.

## 제외 범위

- 클라우드 계정 연동을 통한 자동/주기적 백업 (Google Drive, iCloud API 연동 등) — 이번엔 사용자가 파일을 수동으로 내보내고 가져오는 방식만 지원한다.
- 자세 촬영 영상 파일 자체의 백업 — 영상은 기기 갤러리에 남아있는 것을 전제로 하며, 백업 파일에는 참조 ID만 담긴다. 다른 기기로 복원 시 그 영상은 연결되지 않을 수 있음을 감수한다.
- 백업 데이터의 부분 선택(예: 특정 운동만 내보내기) — 이번엔 전체 데이터를 한 번에 내보내는 것만 지원한다.
- 가져오기 시 기존 데이터와의 병합(merge) — 이번엔 전체 교체만 지원한다.
- 별도의 "설정" 화면 신설 — 진입은 홈 화면 상단 아이콘으로 충분하다.
- 여러 백업 파일 중 자동으로 최신 것을 고르거나 앱 내에서 백업 이력을 관리하는 기능.

## 성공 기준

- [ ] `npx tsc --noEmit` 타입 체크 통과
- [ ] 홈 화면 상단에 백업 진입 아이콘이 보이고, 탭하면 내보내기/가져오기를 고를 수 있는 화면이 뜬다
- [ ] "내보내기"를 실행하면 운동 목록·모든 측정 기록·운동별 설정·테마 설정이 포함된 백업 파일이 생성되고, OS 공유 시트로 전달된다
- [ ] 내보낸 백업 파일에 형식 버전과 내보낸 일시가 포함되어 있다
- [ ] "가져오기"로 정상적인 백업 파일을 선택하면, 적용 전 확인 절차를 거친 뒤 현재 데이터가 파일 내용으로 전체 교체된다
- [ ] 가져오기 확인 전 취소하면 기존 데이터가 전혀 바뀌지 않는다
- [ ] 형식이 다르거나 손상된 파일을 가져오려 하면 오류 메시지가 뜨고 기존 데이터는 그대로 유지된다
- [ ] 가져오기 완료 후 앱을 재시작하지 않아도 홈 화면에 복원된 운동 목록·기록이 바로 보인다
- [ ] 내보내기/가져오기 도중 사용자가 취소해도 앱 상태나 데이터에 부작용이 없다

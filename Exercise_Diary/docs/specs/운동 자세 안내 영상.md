# 운동 자세 안내 영상

## 목적

측정 화면만으로는 이 운동을 정확히 어떤 자세로 해야 하는지 알기 어렵다. 운동마다 유튜브 영상 링크를 등록해두고, 측정 화면에서 바로 열어볼 수 있게 해서 자세를 확인하며 운동할 수 있게 한다.

## 사용자 시나리오

1. 운동을 추가하거나(AddExerciseScreen) 수정할 때(EditExerciseModal), 이름·아이콘 아래에 "자세 영상 링크(선택)" 입력란이 있다. 비워두면 지금과 동일하게 동작한다.
2. 유튜브 영상 링크(`youtube.com/watch?v=...`, `youtu.be/...`, `youtube.com/shorts/...` 형태 모두)를 붙여넣고 저장한다. 유튜브 링크가 아니면 저장 시 안내 메시지가 뜨고 저장되지 않는다.
3. 그 운동의 측정 화면(시간형은 타이머 화면, 횟수·세트형은 세트 입력 화면) 상단에 "자세 영상 보기" 버튼이 나타난다. 링크가 없는 운동에는 이 버튼이 보이지 않는다.
4. 버튼을 탭하면 그 자리에 유튜브 플레이어가 펼쳐지며 영상을 재생할 수 있다. 다시 탭하면 접힌다 — 평소엔 타이머·세트 입력 화면 공간을 그대로 쓴다.
5. 나중에 링크를 수정하거나 비워서 지울 수 있다. 지우면 버튼도 사라진다.

## 요구사항

1. 운동 추가 화면에 "자세 영상 링크" 입력란이 있다 (선택 입력, 비워도 저장 가능).
2. 운동 수정 모달에서도 링크를 추가·수정·삭제할 수 있다 ("매달리기"를 포함해 모든 운동에 동일하게 적용된다).
3. 입력된 링크가 `watch?v=`, `youtu.be/`, `shorts/` 중 하나의 유튜브 URL 형식이 아니면 저장을 거부하고 안내 메시지를 보여준다. 빈 문자열은 "링크 없음"으로 허용된다.
4. 링크가 있는 운동은 측정 화면(TimerScreen 또는 RepsScreen) 상단에 "자세 영상 보기" 토글 버튼이 보인다. 링크가 없으면 버튼 자체가 보이지 않는다.
5. 버튼을 탭하면 그 자리에 유튜브 플레이어가 펼쳐져 영상을 재생할 수 있고, 다시 탭하면 접혀서 원래의 측정 화면 레이아웃으로 돌아온다.
6. 화면 전환(측정↔기록 탭 이동, 홈으로 나가기) 시 펼쳐져 있던 영상은 접힌 상태로 초기화된다 — 다른 화면에서 재생이 이어지지 않는다.

## 제외 범위

- 영상 파일 직접 업로드·자체 호스팅 — 유튜브 링크만 지원한다.
- 운동 하나에 여러 개의 영상 연결 — 하나의 운동에 링크 하나만 저장한다.
- 프리셋 운동에 미리 채워진 공식 안내 영상 — 프리셋도 처음엔 링크가 비어 있고, 사용자가 직접 붙여넣어야 한다.
- 영상 검색·추천 — 링크는 사용자가 직접 찾아서 입력한다.
- 자동 재생 — 펼쳐진 뒤에도 사용자가 유튜브 플레이어의 재생 버튼을 직접 눌러야 재생된다.
- 오프라인 재생, 링크가 실제 존재하는 영상인지 서버로 확인하는 것 — 형식만 검사하고 실제 재생 가능 여부는 유튜브 플레이어에 맡긴다.

## 성공 기준

- [ ] `npx tsc --noEmit` 타입 체크 통과
- [ ] 운동 추가 화면에서 자세 영상 링크(선택)를 입력해 저장할 수 있다
- [ ] 운동 수정 모달에서 링크를 추가·수정·삭제할 수 있다 (매달리기 포함)
- [ ] 유튜브 URL 형식이 아닌 값은 저장이 거부되고 안내 메시지가 보인다
- [ ] 빈 문자열은 "링크 없음"으로 정상 저장된다
- [ ] 링크가 설정된 운동의 측정 화면에 "자세 영상 보기" 버튼이 보인다
- [ ] 링크가 없는 운동은 버튼이 보이지 않는다
- [ ] 버튼을 탭하면 영상이 화면 안에서 펼쳐져 재생 가능한 상태가 되고, 다시 탭하면 접힌다
- [ ] 화면을 벗어났다 돌아오면 영상은 접힌 상태로 초기화돼 있다

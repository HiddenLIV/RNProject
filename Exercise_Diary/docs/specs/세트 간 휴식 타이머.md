# 세트 간 휴식 타이머

## 목적

횟수·세트형 운동(턱걸이·팔굽혀펴기·스쿼트·런지 등)을 측정할 때 세트 사이에 얼마나 쉬어야 하는지 사용자가 직접 시계를 보며 재야 하는 불편을 없앤다. 시간형 운동(플랭크·데드행)에는 이미 벨 간격 알림이 있지만, 횟수형 운동에는 세트 사이를 도와주는 장치가 전혀 없어 실제 헬스장에서 가장 자주 쓰는 흐름 하나가 비어 있다.

## 사용자 시나리오

1. 횟수·세트형 운동의 측정 화면에 들어가면, 무게·횟수 입력 근처에 "휴식 시간" 설정(초 단위)과 켜기/끄기 토글이 보인다. 기본값은 켜짐, 60초.
2. 한 세트를 입력하고 "세트 추가" 버튼을 누르면, 세트가 기록 목록에 즉시 추가되고 동시에 휴식 카운트다운이 자동으로 시작된다.
3. 휴식 중에는 남은 시간이 화면에 크게 표시되고, "건너뛰기" 버튼으로 즉시 휴식을 끝내고 다음 세트 입력으로 돌아갈 수 있다.
4. 휴식 시간이 0에 도달하면 벨 소리와 진동으로 알려주고, 화면은 자동으로 다음 세트를 입력할 수 있는 상태로 돌아간다 — 별도 확인 조작이 필요 없다.
5. 휴식 중에도 "저장" 버튼은 계속 눌러 그동안 기록한 세트를 저장할 수 있다 — 휴식이 다른 조작을 막지 않는다.
6. 휴식 타이머가 필요 없으면 토글을 꺼서, 세트를 추가해도 카운트다운이 뜨지 않게 할 수 있다.
7. 이 운동을 다시 열어도 마지막으로 설정한 휴식 시간·켜기/끄기 상태가 그대로 유지된다.

## 요구사항

1. 횟수·세트형 운동 측정 화면에 휴식 시간(초)을 설정할 수 있는 스테퍼가 보인다. 범위는 10~300초, 10초 단위, 기본값 60초.
2. 같은 화면에 휴식 타이머 켜기/끄기 토글이 있다. 기본값은 켜짐.
3. 켜짐 상태에서 "세트 추가" 버튼을 누르면, 세트가 기록 목록에 추가됨과 동시에 휴식 카운트다운이 자동으로 시작된다.
4. 꺼짐 상태에서는 "세트 추가"를 눌러도 휴식 카운트다운이 시작되지 않고, 지금처럼 바로 다음 세트를 입력할 수 있다.
5. 휴식 중에는 남은 시간이 초 단위로 화면에 표시된다.
6. 휴식 경과 시간은 시작 시각(`Date.now()`) 기준으로 계산한다 — 앱을 백그라운드로 보냈다 돌아와도 남은 시간이 정확해야 한다.
7. 휴식 중 "건너뛰기" 버튼으로 즉시 휴식을 종료하고 다음 세트 입력 상태로 돌아갈 수 있다.
8. 휴식 시간이 0에 도달하면 벨 소리(기존 벨 사운드 재사용)와 진동(haptic)으로 알려준다.
9. 휴식이 끝나면(0 도달 또는 건너뛰기) 화면은 자동으로 다음 세트를 입력할 수 있는 상태로 돌아간다.
10. 휴식 중에도 저장 버튼, 무게·횟수 입력, 영상 촬영 버튼은 계속 조작 가능하다.
11. 세트를 삭제해도 진행 중인 휴식 타이머는 영향받지 않고 계속 진행된다.
12. 휴식 시간(초)과 켜기/끄기 설정은 운동별로 저장되어, 같은 운동을 다시 열면 마지막 설정값이 그대로 적용된다.
13. 앱을 백그라운드로 보냈다가 휴식 시간이 다 지난 뒤 복귀하면, 화면은 바로 "휴식 종료" 상태(다음 세트 입력 가능)로 보이고 그 시점에 뒤늦게 알림음이 울리지 않는다.
14. 휴식 중 화면이 자동 잠금되지 않는다 (기존 측정 중 동작과 동일한 원칙).
15. 설정 라벨과 관련 문구는 4개 지원 언어(ko/en/ja/zh) 모두 번역되어 표시된다.

## 제외 범위

- 휴식 시간 연장/단축 버튼(예: +15초) — 이번엔 건너뛰기만 지원, 연장은 다음 버전에서 검토
- 휴식 중 음성(TTS)으로 초를 읽어주는 안내 — 시간형 운동과 달리 벨+진동만 사용한다
- 휴식 중 다른 앱 음악을 일시정지시키는 오디오 포커스 점유 — 벨 소리는 짧게 겹쳐 재생되고 음악은 끊기지 않는다
- 실제로 얼마나 쉬었는지를 기록(RepsRecord)에 저장하는 것 — 이번엔 화면 안내용일 뿐, 기록 데이터에는 남기지 않는다
- 세트별로 다른 휴식 시간을 예약하는 기능(예: 마지막 세트만 더 길게) — 운동당 하나의 값만 지원
- 시간형 운동(플랭크·데드행)의 벨 간격 설정 변경 — 이번 기능은 횟수·세트형 운동에만 적용된다
- 세트 추가 없이 수동으로 "휴식 시작"만 누르는 기능 — 세트 추가 시 자동 시작만 지원

## 성공 기준

- [ ] `npx tsc --noEmit` 타입 체크 통과
- [ ] 횟수·세트형 운동 측정 화면에 휴식 시간 스테퍼(10~300초, 10초 단위, 기본 60초)와 켜기/끄기 토글(기본 켜짐)이 보인다
- [ ] 휴식 타이머가 켜진 상태에서 세트를 추가하면 휴식 카운트다운이 자동으로 시작된다
- [ ] 휴식 타이머가 꺼진 상태에서는 세트를 추가해도 카운트다운이 뜨지 않는다
- [ ] 휴식 중 남은 시간이 화면에 초 단위로 표시된다
- [ ] 휴식 중 앱을 백그라운드로 보냈다 복귀해도 남은 시간이 실제 경과 시간과 일치한다
- [ ] "건너뛰기" 버튼을 누르면 즉시 휴식이 끝나고 다음 세트 입력 상태로 돌아간다
- [ ] 휴식 시간이 0에 도달하면 벨 소리와 진동이 울린다
- [ ] 휴식이 끝나면 별도 확인 없이 자동으로 다음 세트 입력 상태로 돌아간다
- [ ] 휴식 중에도 저장 버튼으로 그때까지의 세트를 저장할 수 있다
- [ ] 세트를 삭제해도 진행 중인 휴식 타이머는 계속 진행된다
- [ ] 휴식 시간·켜기/끄기 설정을 바꾸고 그 운동 화면을 나갔다 다시 들어가도 값이 유지된다
- [ ] 휴식 시간이 이미 다 지난 뒤 앱을 복귀하면 뒤늦게 알림음 없이 바로 종료 상태로 보인다
- [ ] 휴식 중 화면이 자동 잠금되지 않는다
- [ ] 설정 라벨이 한국어·영어·일본어·중국어 모두 번역되어 보인다

# 광고 노출

## 목적

앱은 현재 수익 모델이 전혀 없다. 배너 광고와 전면 광고를 도입해 기본적인 광고 수익을 만든다. 배너는 홈 화면에 상시 노출해 꾸준한 노출 수익을 확보하고, 전면 광고는 사용자가 운동을 어느 정도 등록해 앱에 정착한 시점부터 운동을 추가할 때마다 노출해 단가가 높은 광고 수익을 더한다.

## 사용자 시나리오

**배너 광고**
1. 사용자가 홈 화면에 있는 동안에는 운동 등록 개수와 무관하게 홈 화면 최하단에 배너 광고가 항상 보인다.
2. 배너는 홈 화면에서만 보이며, 측정 화면(타이머/횟수)이나 운동 추가·수정 화면 등 다른 화면에서는 보이지 않는다.
3. 네트워크 오류 등으로 광고가 로드되지 않으면, 그 자리는 빈 공간 없이 자연스럽게 처리되어 홈 화면의 다른 UI(운동 목록 등)를 가리거나 방해하지 않는다.

**전면 광고**
4. 사용자가 운동을 처음부터 2개까지 등록하는 동안에는 전면 광고가 전혀 뜨지 않는다 — 온보딩 단계에서 광고로 인한 이탈을 막는다.
5. 사용자가 운동을 3번째로 등록하면, 저장이 끝나고 홈 화면으로 돌아가는 시점에 전면 광고가 한 번 뜬다.
6. 이후 운동을 6번째, 9번째, 12번째… 로 3개씩 늘려서 등록할 때마다 같은 방식으로 전면 광고가 다시 뜬다(4·5번째, 7·8번째처럼 그 사이 등록 시점에는 뜨지 않는다).
7. 전면 광고는 사용자가 닫기 전까지 화면을 덮으며, 사용자가 닫으면 홈 화면으로 돌아간다.
8. 전면 광고 표시 여부와 무관하게 기존 홈 화면·운동 추가 화면 기능(운동 목록 스크롤, 운동 선택, 운동 추가 버튼, 상단 도움말·백업 아이콘 등)은 동일하게 동작한다.

## 요구사항

1. 배너 광고는 홈 화면 최하단에 고정 노출되며, 등록된 운동 개수와 무관하게 항상 보인다.
2. 배너는 홈 화면에서만 노출되며, 측정 화면(`ExerciseScreen`, 타이머/횟수 측정 중)과 운동 추가/수정 화면(`AddExerciseScreen`)에는 노출되지 않는다.
3. 배너는 운동 목록 스크롤과 무관하게 항상 화면 최하단에 보이며, 운동 목록 콘텐츠에 가려지지 않는다.
4. 전체 등록 운동 개수가 3개가 되는 시점(3번째 운동 등록 완료)에 전면 광고가 1회 노출된다.
5. 그 이후로도 전체 등록 운동 개수가 3의 배수(6, 9, 12…)로 늘어날 때마다 같은 방식으로 전면 광고가 노출된다. 그 사이 개수(4, 5, 7, 8…) 등록에는 노출되지 않는다.
6. 전면 광고는 운동 추가가 저장된 직후, 홈 화면으로 전환되기 전에 노출된다.
7. 전면 광고 노출 기준이 되는 "등록 운동 개수"는 현재 실시간으로 등록되어 있는 총 운동 개수를 기준으로 한다(삭제로 개수가 줄었다가 다시 해당 지점에 도달하면 다시 노출될 수 있다).
8. 배너·전면 광고 모두 Google AdMob을 사용한다.
9. 광고 로드가 실패하거나 지연되는 경우, 배너는 빈 공간 없이 자연스럽게 처리되고, 전면 광고는 뜨지 않은 채 정상적으로 홈 화면으로 전환된다(운동 추가 자체가 막히지 않는다).
10. 라이트/다크 테마 어느 쪽에서도 배너 주변 배경이 앱 테마와 부자연스럽게 이질적으로 보이지 않는다(광고 콘텐츠 자체는 광고 네트워크가 결정하므로 배경·여백 정도만 앱 테마에 맞춘다).
11. 실제 배포 전에는 AdMob 테스트 광고 단위 ID(배너·전면 각각)로 동작을 확인할 수 있어야 하고, 실제 광고 단위 ID로 손쉽게 교체할 수 있어야 한다.
12. 개인정보처리방침(`docs/privacy-policy.html`)에 광고 SDK를 통한 데이터 수집 사실이 반영된다.

## 제외 범위

- 보상형(rewarded) 광고 등 배너·전면 이외의 광고 포맷.
- 인앱결제를 통한 "광고 제거" 유료화 옵션 — 이번 스펙 범위 밖이며, 필요 시 별도 스펙으로 진행한다.
- 홈 화면 이외의 화면(측정 화면, 운동 추가/수정 화면, 기록 화면 등)에 배너 광고를 노출하는 것.
- 운동 추가 이외의 시점(예: 세트 완료, 앱 실행 시)에 전면 광고를 추가로 노출하는 것.
- 사용자별/지역별 맞춤 광고 노출 정책, 광고 빈도 제한(frequency capping) 등 AdMob 자체 기본 동작을 벗어나는 세부 정책 커스터마이징.
- 광고 수익 분석 대시보드나 자체 로깅.

## 성공 기준

- [ ] `npx tsc --noEmit` 타입 체크 통과
- [ ] 홈 화면에서는 운동 등록 개수와 무관하게 항상 최하단에 배너 광고가 보인다
- [ ] 측정 화면, 운동 추가/수정 화면에는 배너 광고가 노출되지 않는다
- [ ] 배너가 홈 화면 운동 목록 스크롤과 무관하게 항상 최하단에 고정되어 보인다
- [ ] 운동을 3번째로 등록하면 저장 직후 전면 광고가 1회 노출된 뒤 홈 화면으로 돌아간다
- [ ] 운동을 4·5번째로 등록할 때는 전면 광고가 뜨지 않고, 6번째로 등록할 때 다시 전면 광고가 뜬다(이후 9, 12…도 동일)
- [ ] 운동을 삭제해 개수가 줄었다가 다시 3개/6개 등 해당 지점에 도달하면 전면 광고가 다시 노출된다
- [ ] 광고 로드 실패/지연 시에도 홈 화면 레이아웃이 깨지지 않고, 운동 추가 흐름이 막히지 않는다
- [ ] 라이트/다크 테마 각각에서 배너 주변이 자연스럽게 보인다
- [ ] 배너·전면 모두 테스트 광고 단위 ID로 정상 동작을 확인했고, 실제 광고 단위 ID로 교체 가능한 구조다
- [ ] 개인정보처리방침에 광고 SDK 데이터 수집 관련 내용이 반영되어 있다

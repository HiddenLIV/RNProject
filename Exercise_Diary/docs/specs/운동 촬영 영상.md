# 운동 촬영 영상

## 목적

운동 자세 안내 영상이 남이 만든 유튜브 영상을 보여주는 기능이라면, 이 기능은 사용자 자신이 운동하는 모습을 직접 촬영해 기록과 함께 남기는 기능이다. 나중에 자신의 자세를 다시 돌려보며 확인할 수 있게 한다.

## 사용자 시나리오

1. 측정 화면(TimerScreen 또는 RepsScreen)에 "촬영" 버튼이 있다. 타이머 진행이나 세트 입력과 무관하게 언제든 누를 수 있다.
2. 버튼을 누르면 카메라가 열려 동영상을 찍을 수 있고, 촬영이 끝나면 영상은 기기 갤러리에 저장된다. 앱은 영상 파일 자체를 복사해 자기 저장소에 보관하지 않는다.
3. 같은 측정 세션(그 화면에 들어와서 기록을 저장하기 전까지) 동안 촬영한 영상은, 그 세션에서 기록을 저장하는 시점에 저장되는 기록과 자동으로 연결된다.
4. 촬영 직후 측정 화면에서 방금 찍은 영상을 그 자리에서 바로 재생해볼 수 있다.
5. 기록을 저장하지 않고 화면을 벗어나면(뒤로 가기 등), 촬영한 영상은 갤러리에는 남아있지만 어떤 기록과도 연결되지 않는다.
6. 기록(RecordsScreen)에서 과거 기록을 볼 때, 영상이 연결된 기록은 구분되어 보이고 선택하면 그 영상을 열어 재생할 수 있다.
7. 영상이 연결된 기록을 앱에서 삭제해도, 기기 갤러리에 있는 실제 영상 파일은 삭제되지 않는다 — 기록과의 연결 정보만 사라진다.
8. 나중에 그 영상을 기기 갤러리에서 직접 지웠다면, 앱에서 다시 재생을 시도할 때 오류 화면 대신 "영상을 찾을 수 없다"는 안내가 뜬다.
9. 처음으로 "촬영" 버튼을 누르면, 곧바로 OS 권한 팝업이 뜨는 대신 앱이 왜 카메라·사진 접근 권한이 필요한지 설명하는 권한 요청 페이지가 먼저 뜬다. 여기서 "권한 허용" 같은 버튼을 눌러야 실제 OS 권한 요청이 진행된다.
10. OS가 더 이상 권한 재요청 팝업을 띄워주지 않는 상태(iOS는 첫 거부 즉시 이 상태가 되고, 안드로이드는 통상 두 번째 거부 또는 "다시 묻지 않음" 선택 이후 이 상태가 된다)에서 촬영 버튼을 누르면, 같은 권한 요청 페이지가 뜨는데 이번엔 "권한 허용" 대신 기기의 앱 설정 화면으로 바로 이동하는 버튼이 보인다. 안드로이드에서 재요청이 아직 가능한 1차 거부 상태라면 "권한 허용" 버튼이 그대로 뜨고, 누르면 OS 팝업이 다시 뜬다.

## 요구사항

1. TimerScreen과 RepsScreen 모두에 측정 진행 상태와 무관하게 언제든 누를 수 있는 "촬영" 버튼이 있다.
2. 촬영 버튼을 누르면 카메라로 동영상을 찍을 수 있고, 촬영을 마치면 기기 갤러리(사진 앱)에 저장된다.
3. 앱은 촬영된 영상 파일을 자체 저장소에 복사하지 않는다. 기록과 영상을 연결하기 위해 갤러리 상의 위치를 가리키는 참조 정보만 기록 데이터에 저장한다.
4. 같은 측정 세션에서 촬영한 영상은 그 세션의 기록을 저장하는 시점에 해당 기록에 연결된다. 한 세션에서 여러 번 촬영했다면 마지막으로 촬영한 영상이 연결된다(기록당 영상은 최대 1개).
5. 기록을 저장하지 않고 화면을 벗어나면, 촬영된 영상은 갤러리에는 남지만 어떤 기록과도 연결되지 않는다.
6. 측정 화면에서 방금 촬영한 영상을 그 자리에서 다시 재생해볼 수 있다.
7. 기록(RecordsScreen) 목록에서 영상이 연결된 기록은 구분되어 표시되고, 선택하면 연결된 영상을 재생할 수 있다.
8. 영상이 연결된 기록을 삭제해도 기기 갤러리의 영상 파일은 삭제되지 않는다.
9. 연결된 영상을 재생하려 할 때 갤러리에서 이미 삭제·이동되어 찾을 수 없는 상태라면, 앱이 오류로 멈추지 않고 "영상을 찾을 수 없다"는 안내를 보여준다.
10. 카메라 접근 권한 또는 갤러리 저장 권한을 사용자가 거부한 경우, 촬영 버튼을 눌렀을 때 권한이 필요하다는 안내가 뜨고 앱이 멈추거나 크래시하지 않는다.
11. 카메라·사진 권한이 아직 한 번도 요청된 적 없는 상태에서 "촬영" 버튼을 처음 누르면, OS 권한 팝업 대신 앱이 만든 권한 안내 페이지가 먼저 뜬다. 이 페이지에는 왜 권한이 필요한지 설명과 "권한 허용" 버튼이 있고, 버튼을 누르면 그때 실제 OS 권한 요청이 진행된다.
12. OS가 더 이상 권한 재요청 팝업을 띄워주지 않는 상태(iOS는 첫 거부 즉시, 안드로이드는 통상 두 번째 거부 이후)에서 "촬영" 버튼을 누르면 같은 안내 페이지가 뜨되, "권한 허용" 버튼 대신 기기의 이 앱 설정 화면으로 바로 이동하는 버튼이 보인다. 안드로이드에서 재요청이 가능한 1차 거부 상태에는 "권한 허용" 버튼이 그대로 뜬다 — OS 표준 재요청 흐름을 그대로 따른다.
13. 권한을 이미 허용한 사용자에게는 이 안내 페이지가 뜨지 않는다 — 촬영 버튼을 누르면 바로 카메라가 열린다.

## 제외 범위

- 영상 편집(자르기·필터·트리밍 등) — 촬영한 그대로 저장한다.
- 기록 하나에 영상을 여러 개 연결하는 것 — 기록당 영상은 최대 1개다.
- 영상 클라우드 백업·기기 간 동기화 — 기기 갤러리에 저장하는 것까지만 다룬다.
- 촬영한 영상을 앱 안에서 다른 사람에게 공유하는 기능.
- 타이머 시작·종료와 녹화 시작·종료의 자동 연동 — 촬영은 항상 수동 "촬영" 버튼으로만 시작한다.
- 이미 기기 갤러리에 있는 기존 영상을 불러와 기록에 연결하는 기능 — 이번 기능은 새로 촬영하는 흐름만 다룬다.

## 성공 기준

- [ ] `npx tsc --noEmit` 타입 체크 통과
- [ ] TimerScreen, RepsScreen 모두에서 "촬영" 버튼이 보이고 측정 진행 상태와 무관하게 언제든 누를 수 있다
- [ ] 촬영 버튼으로 동영상을 찍으면 기기 갤러리에 저장된다
- [ ] 앱 자체 저장소에는 영상 파일이 복사되지 않는다 (기록에는 참조 정보만 저장된다)
- [ ] 같은 측정 세션에서 촬영한 영상이 기록을 저장할 때 그 기록에 연결된다
- [ ] 기록을 저장하지 않고 화면을 벗어나면 영상은 갤러리에는 남지만 어떤 기록에도 연결되지 않는다
- [ ] 측정 화면에서 방금 찍은 영상을 그 자리에서 바로 재생해볼 수 있다
- [ ] 기록 목록에서 영상이 연결된 기록을 구분할 수 있고, 선택하면 연결된 영상을 재생할 수 있다
- [ ] 기록을 삭제해도 기기 갤러리의 영상 파일은 남아있다
- [ ] 갤러리에서 영상이 사라진 뒤 재생을 시도하면 앱이 멈추지 않고 안내 메시지가 뜬다
- [ ] 카메라·갤러리 권한을 거부해도 앱이 크래시하지 않고 안내 메시지가 뜬다
- [ ] 권한을 한 번도 요청한 적 없는 상태에서 촬영 버튼을 처음 누르면 OS 팝업 전에 앱의 권한 안내 페이지가 먼저 뜬다
- [ ] 안내 페이지에서 "권한 허용"을 누르면 실제 OS 권한 요청이 진행된다
- [ ] OS가 재요청 팝업을 더 이상 안 띄우는 상태(iOS 첫 거부, 안드로이드 통상 두 번째 거부)에서 촬영 버튼을 누르면 안내 페이지에 "설정으로 이동" 버튼이 보이고, 누르면 기기의 앱 설정 화면으로 이동한다
- [ ] 안드로이드에서 재요청이 아직 가능한 1차 거부 상태라면 "권한 허용" 버튼이 그대로 뜬다
- [ ] 권한을 이미 허용한 사용자는 촬영 버튼을 눌러도 안내 페이지 없이 바로 카메라가 열린다

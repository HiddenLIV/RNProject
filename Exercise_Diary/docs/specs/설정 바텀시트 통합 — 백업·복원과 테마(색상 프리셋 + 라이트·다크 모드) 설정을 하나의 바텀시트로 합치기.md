# 설정 바텀시트 통합 — 백업·복원과 테마(색상 프리셋 + 라이트·다크 모드) 설정을 하나의 바텀시트로 합치기

## 목적

지금 홈 화면 헤더에는 백업/복원 진입 아이콘(구름)과 포인트 컬러 스와치 5개가 항상 나란히 노출돼 있고, 라이트·다크 모드는 기기 시스템 설정만 따를 뿐 앱 안에서 고를 방법이 없다. 설정류 진입점이 헤더에 흩어져 있어 앞으로 항목이 늘어날수록 헤더가 계속 붐비는 구조다. 백업/복원과 테마 관련 설정(색상 프리셋 + 새로 추가하는 라이트/다크 모드 선택)을 "설정" 바텀시트 하나로 모아, 헤더는 가볍게 유지하면서 사용자가 원할 때 한 곳에서 앱을 자신에게 맞게 조정할 수 있게 한다.

이 기능은 아래 기존 스펙의 일부 결정을 갱신한다:
- [데이터 백업 및 내보내기](데이터%20백업%20및%20내보내기.md) 제외 범위의 "별도의 설정 화면 신설 — 진입은 홈 화면 상단 아이콘으로 충분하다"
- [테마 컬러 커스터마이징](테마%20컬러%20커스터마이징.md) 제외 범위의 "별도의 설정 화면 신설 — 진입은 홈 화면 상단 스와치로 충분"
- [라이트 모드 지원](라이트%20모드%20지원.md) 제외 범위의 "앱 내 라이트/다크 수동 선택 토글·설정 화면 (이번엔 시스템 설정 자동 반영만 지원)"

## 사용자 시나리오

1. 홈 화면 헤더에는 이제 도움말(`?`) 아이콘과 설정(톱니바퀴) 아이콘 두 개만 보인다. 기존 백업(구름) 아이콘과, 헤더에 항상 떠 있던 포인트 컬러 스와치 5개는 더 이상 헤더에 노출되지 않는다.
2. 설정 아이콘을 탭하면 바텀시트가 아래에서 올라오고, 그 안에 "포인트 컬러", "화면 모드(라이트/다크)", "백업/복원" 세 영역이 순서대로 보인다.
3. 포인트 컬러 영역에는 기존과 동일한 원형 스와치 5개가 있고, 탭하면 확인 절차 없이 즉시 앱 전체에 반영된다(기존 동작 그대로).
4. 화면 모드 영역에는 "시스템 설정 따름 / 라이트 / 다크" 세 가지를 고르는 선택지가 있다. 기본값은 "시스템 설정 따름"이라, 이번 기능을 처음 만나는 기존 사용자의 화면은 바뀌지 않는다.
   - "시스템 설정 따름"을 고르면 기기 디스플레이 설정을 따라가며, 기기 설정이 바뀌면 앱 재시작 없이 즉시 반영된다(지금까지의 동작).
   - "라이트" 또는 "다크"를 고르면 기기 설정과 무관하게 그 모드로 고정되고, 앱을 재시작해도 유지된다.
5. 백업/복원 영역에는 기존과 동일하게 "내보내기" / "가져오기" 두 행이 있고, 동작 방식은 기존 백업 기능과 동일하다.
6. 백업 파일을 내보내면 포인트 컬러 프리셋과 함께 화면 모드 선택값(시스템 따름/라이트/다크)도 포함된다. 다른 기기(또는 초기화한 같은 기기)에서 그 파일을 가져오면 화면 모드 선택도 그대로 복원된다.
7. 설정 시트 안에서 포인트 컬러나 화면 모드를 바꿔도 시트는 닫히지 않고 계속 열려 있어, 이어서 백업까지 한 번에 처리할 수 있다.
8. 시트를 닫으면(백드롭 탭, 닫기 버튼, 안드로이드 뒤로 가기) 그동안 고른 포인트 컬러·화면 모드는 그대로 적용된 채 유지된다.

## 요구사항

1. 홈 화면 헤더의 백업(구름) 아이콘을 설정(톱니바퀴 등) 아이콘으로 교체한다. 도움말(`?`) 아이콘은 그대로 별도로 유지한다.
2. 헤더에 항상 노출되던 포인트 컬러 스와치 5개(`ThemeSwatchRow`)는 헤더에서 제거하고, 설정 시트 내부로 이동한다.
3. 설정 아이콘을 탭하면 바텀시트가 열리고, 그 안에 포인트 컬러 선택, 화면 모드 선택, 백업/복원 세 섹션이 한 화면(시트) 안에서 모두 보인다(추가 탭 전환이나 하위 화면 이동 없이 스크롤만으로 접근 가능).
4. 포인트 컬러 선택 섹션은 기존 [테마 컬러 커스터마이징](테마%20컬러%20커스터마이징.md) 스펙의 동작(5개 프리셋, 즉시 반영, 재시작해도 유지)을 그대로 유지한다 — 이번 기능으로 그 동작 자체는 바뀌지 않는다.
5. 화면 모드 선택 섹션은 "시스템 설정 따름 / 라이트 / 다크" 3가지 중 하나를 고르는 UI를 제공하며, 현재 선택된 값이 시각적으로 구분되어 보인다.
6. 화면 모드를 "라이트" 또는 "다크"로 고르면 기기 시스템 설정과 무관하게 앱 전체(모든 화면)가 그 모드의 배경/카드/텍스트 팔레트로 즉시 전환된다.
7. 화면 모드를 "시스템 설정 따름"으로 고르면 [라이트 모드 지원](라이트%20모드%20지원.md) 스펙의 기존 동작(기기 설정을 실시간으로 따라가며, 앱이 실행 중에 기기 설정이 바뀌어도 즉시 반영)대로 동작한다.
8. 화면 모드 선택값은 기기에 저장되어 앱을 재시작해도 유지된다. 최초 설치 시 기본값은 "시스템 설정 따름"이다(기존 사용자·신규 사용자 모두 업데이트 직후 화면이 바뀌지 않는다).
9. 백업/복원 섹션은 기존 [데이터 백업 및 내보내기](데이터%20백업%20및%20내보내기.md) 스펙의 요구사항(내보내기/가져오기, 확인 절차, 오류 처리 등)을 그대로 유지한다.
10. 백업 내보내기 파일에는 포인트 컬러 프리셋과 함께 화면 모드 선택값("시스템 따름"/"라이트"/"다크")이 포함된다.
11. 백업 가져오기를 확인하면, 운동 데이터·포인트 컬러 프리셋과 함께 화면 모드 선택값도 백업 파일 내용으로 교체된다.
12. 화면 모드가 없는(이번 기능 이전 형식의) 백업 파일을 가져올 경우, 화면 모드는 "시스템 설정 따름"으로 처리한다(가져오기 자체가 실패하지 않는다).
13. 설정 시트 안에서 포인트 컬러나 화면 모드를 바꿔도 시트는 닫히지 않고, 이어서 다른 섹션(백업 등)을 계속 조작할 수 있다.
14. 도움말 시트는 이번 기능과 무관하게 지금처럼 별도로 유지된다(설정 시트에 포함되지 않는다).

## 제외 범위

- 언어(다국어) 선택을 설정 시트에 포함하는 것 — 이번엔 색상 프리셋·화면 모드·백업/복원만 다룬다.
- 알림음, 진동(햅틱) on/off처럼 이번에 새로 정의되지 않은 다른 설정 항목 추가.
- 화면 모드를 앱마다가 아니라 특정 화면(예: 타이머 측정 중만 다크 고정)별로 다르게 적용하는 기능 — 화면 모드는 앱 전체에 항상 동일하게 적용된다.
- 설정 시트 내 섹션 순서를 사용자가 바꾸는 커스터마이징.
- 화면 모드에 "시스템 따름/라이트/다크" 외의 추가 옵션(예: 예약 시간에 따른 자동 전환).
- 헤더 아이콘 디자인(톱니바퀴 모양 등 구체적 아이콘)의 확정 — 구체적 아이콘 선택은 /design에서 다룬다.

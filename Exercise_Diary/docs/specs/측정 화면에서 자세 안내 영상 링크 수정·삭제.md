# 측정 화면에서 자세 안내 영상 링크 수정·삭제

## 목적

이미 등록된 자세 안내 영상 링크를 바꾸거나 지우려면 홈 화면으로 나가 운동 수정 모달을 열어야 한다. 앞서 추가한 "측정 화면에서 링크 추가" 기능과 짝을 맞춰, 이미 있는 링크도 측정 화면에서 바로 수정·삭제할 수 있게 해서 왕복을 없앤다.

## 사용자 시나리오

1. 자세 안내 영상 링크가 등록된 운동의 측정 화면에서 "자세 영상 보기" 토글 버튼 옆에 연필(수정) 아이콘이 보인다.
2. 연필 아이콘을 탭하면 현재 링크가 채워진 입력란과 삭제·취소·저장 버튼이 그 자리에 펼쳐진다 (재생 중이던 영상은 접힌다).
3. 링크를 다른 유튜브 링크로 바꿔서 저장하면, 그 자리가 새 링크를 반영한 "자세 영상 보기" 토글 버튼으로 되돌아간다.
4. 저장하려는 값이 유튜브 링크 형식이 아니면 저장이 거부되고 안내 메시지가 보인다.
5. "삭제"를 누르면 정말 지울지 확인하는 팝업이 뜨고, 확인하면 링크가 삭제되어 그 자리가 "자세 영상 링크 추가" 버튼(링크 없음 상태)으로 바뀐다.
6. "취소"를 누르면 변경 없이 원래의 "자세 영상 보기" 토글 버튼 상태로 되돌아간다.
7. 시간형 운동(타이머 화면)과 횟수·세트형 운동(세트 입력 화면) 모두 동일하게 동작한다.
8. 이 화면에서 수정·삭제한 결과는 홈 화면의 운동 수정 모달에도 그대로 반영된다 (같은 데이터를 공유).
9. 타이머를 한 번 측정하고 돌아오거나 기록 탭에 갔다 와도 수정·삭제 결과가 유지된다 (직전 "링크 추가" 기능에서 고친 상태 유지 방식을 그대로 따른다).

## 요구사항

1. 자세 안내 영상 링크가 있는 운동의 측정 화면에서, "자세 영상 보기" 토글 버튼 옆에 수정(연필) 아이콘이 보인다.
2. 수정 아이콘을 탭하면 현재 링크로 채워진 입력란과 삭제·취소·저장 버튼이 그 자리에 펼쳐진다. 펼쳐져 있던 영상 플레이어가 있었다면 접힌다.
3. 입력한 값이 유튜브 URL 형식(watch?v=, youtu.be/, shorts/)이 아니면 저장이 거부되고 안내 메시지가 표시된다.
4. 유효한 링크로 저장하면 그 운동의 링크가 새 값으로 갱신되고, 화면이 곧바로 갱신된 "자세 영상 보기" 토글 버튼으로 돌아간다.
5. "삭제" 버튼을 누르면 삭제 여부를 확인하는 팝업이 뜬다. 확인하면 그 운동의 링크가 삭제되고, 화면이 "자세 영상 링크 추가" 버튼(링크 없음 상태)으로 바뀐다. 팝업에서 취소하면 아무 변화 없이 입력 폼이 유지된다.
6. "취소" 버튼을 누르면 입력 내용은 버려지고 변경 전 링크를 그대로 유지한 "자세 영상 보기" 토글 버튼 상태로 돌아간다.
7. 시간형 운동의 측정 화면(TimerScreen)과 횟수·세트형 운동의 측정 화면(RepsScreen) 모두에서 동일하게 동작한다.
8. 이 방법으로 수정·삭제한 결과는 홈 화면의 운동 수정 모달에도 동일하게 반영된다 — 별도의 저장소를 쓰지 않는다.
9. 타이머 측정을 한 번 진행하고 돌아오거나 측정↔기록 탭을 전환해도, 방금 수정·삭제한 결과가 유지된다 (화면을 벗어나 전체 앱을 나가기 전까지).
10. 링크가 없는 운동의 기존 "추가" 흐름(직전 기능)은 이번 변경으로 영향받지 않는다.

## 제외 범위

- 삭제한 링크를 되돌리는 "실행 취소" 기능 — 삭제 후 되돌리려면 다시 링크를 입력해야 한다.
- 새로운 유튜브 링크 검증 규칙 도입 — 기존 검증 로직을 그대로 재사용한다.
- 새로 필요해지는 문구의 구체적 번역 문안 — 기존 4개 언어 번역 체계에 맞춰 추가하되, 세부 문구는 /dev 단계에서 정한다.
- 여러 링크 등록 — 하나의 운동에 링크 하나만 저장하는 기존 원칙을 유지한다.

## 성공 기준

- [ ] `npx tsc --noEmit` 타입 체크 통과
- [ ] 링크가 있는 운동의 측정 화면에 수정(연필) 아이콘이 토글 버튼 옆에 보인다 (타이머 화면, 세트 입력 화면 모두)
- [ ] 수정 아이콘을 탭하면 현재 링크가 채워진 입력란과 삭제·취소·저장 버튼이 펼쳐진다
- [ ] 유튜브 URL 형식이 아닌 값으로 저장하려 하면 거부되고 안내 메시지가 보인다
- [ ] 유효한 링크로 저장하면 링크가 갱신되고 화면이 즉시 갱신된 토글 버튼으로 돌아간다
- [ ] 삭제 버튼을 누르면 확인 팝업이 뜨고, 확인해야만 실제로 삭제된다
- [ ] 삭제 후 화면이 "자세 영상 링크 추가" 버튼(링크 없음 상태)으로 바뀐다
- [ ] 취소를 누르면 변경 없이 원래 링크가 유지된 토글 버튼 상태로 돌아간다
- [ ] 수정·삭제 결과가 홈 화면의 운동 수정 모달에도 동일하게 반영된다
- [ ] 타이머 측정 1회 진행 후 또는 기록 탭 전환 후에도 수정·삭제 결과가 유지된다
- [ ] 링크 없는 운동의 기존 "추가" 흐름은 이번 변경으로 영향받지 않는다
- [ ] 새로 추가된 문구가 4개 언어(한국어/영어/일본어/중국어) 모두에 번역되어 있다

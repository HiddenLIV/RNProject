# Play Console 등록 카피 — 복붙용

Play Console → 스토어 등록정보 작성 시 그대로 붙여넣을 수 있도록 정리한 문서. 값이 바뀌면 이 파일도 같이 업데이트.

## 앱 이름 (30자 이내)

```
HiddenReps: 나만의 운동 기록
```

## 짧은 설명 (80자 이내)

```
원하는 운동을 직접 추가해 시간·횟수·세트를 정확히 남기는 심플한 운동 일지
```

## 긴 설명 (4000자 이내)

```
* 별도의 회원가입이나 로그인 없이, 설치 즉시 바로 사용할 수 있습니다.
* 운동 기록과 촬영 영상은 모두 기기에만 저장되며, 서버로 전송되지 않습니다.

HiddenReps는 원하는 운동을 직접 추가해 시간과 횟수·세트를 정확하게 측정하고 기록하는
개인용 운동 일지 앱입니다.
운동 이름과 아이콘, 측정 방식(시간 또는 횟수·세트)까지 전부 내 손으로 정해서, 어떤 운동이든
나만의 방식으로 기록할 수 있습니다.

[주요기능]
1. 운동 커스터마이징
프리셋에서 고르거나 이름·아이콘·색상을 직접 정해 나만의 운동을 추가합니다. 측정 방식(시간 /
횟수·세트)과 무게 기록 여부도 운동마다 선택할 수 있습니다.

2. 시간 · 횟수·세트 측정
버틴 시간을 재는 운동은 초 단위로, 반복하는 운동은 세트별 횟수와 무게까지 정확하게
기록합니다.

3. 기록 관리
운동별 최고 기록과 세트별 상세 기록을 한눈에 확인하고, 기록 시간도 직접 보정할 수 있습니다.

4. 촬영 기록 · 자세 안내
운동하는 모습을 영상으로 남겨 다시 돌려보거나, 운동별로 참고할 YouTube 영상 링크를 등록해
측정 화면에서 바로 재생합니다.

5. 데이터 백업
운동 기록을 파일로 내보내 보관하거나, 기기를 옮길 때 백업 파일로 그대로 복원합니다.

6. 테마 · 다국어
라이트/다크 모드를 취향대로 커스터마이징하고, 한국어·영어·일본어·중국어를 지원합니다.

[선택적접근권한]
-----------------------------------------------------
항목                     이유
-----------------------------------------------------
카메라권한              운동하는 모습 촬영
마이크권한              촬영한 영상에 소리 녹음
사진(미디어)권한         촬영한 영상 저장 및 불러오기
-----------------------------------------------------
※선택적 접근권한을 허용하지 않아도 시간·횟수 측정, 기록 관리 등 기본 기능은 이용할 수
있습니다. 촬영 관련 기능만 제한됩니다.

앱에는 Google AdMob 광고가 포함되어 있으며, 광고 제공 과정에서 처리되는 데이터에는
Google의 정책이 적용됩니다.
```

## 데이터 안전(Data Safety) 양식 답변

이 앱은 카메라·마이크·사진 권한을 요청하지만, 촬영된 영상/사진과 운동 기록은 모두
기기 로컬(AsyncStorage, 파일시스템)에만 저장되고 서버로 전송되지 않습니다.
다만 Google AdMob 광고 SDK가 광고 제공 과정에서 광고 ID 등 기기 식별자를 수집·전송하므로,
"수집 없음"으로는 답할 수 없고 아래처럼 광고 ID 항목만 수집으로 신고합니다.

| 질문 | 답변 |
|---|---|
| 앱이 사용자 데이터를 수집 또는 공유합니까? | **예** |
| 수집되는 데이터 유형 | 기기 또는 기타 ID (광고 ID) |
| 수집 목적 | 광고 또는 마케팅 |
| 이 데이터는 앱 기능에 필수인가요, 선택인가요? | 선택 — 사용자가 기기 설정에서 광고 개인화를 제한할 수 있음 |
| 제3자와 공유됩니까? | 예 — Google(AdMob) |
| 데이터가 암호화되어 전송됩니까? | 예 (AdMob SDK가 전송 구간 암호화) |
| 사용자가 데이터 삭제를 요청할 수 있습니까? | 해당 없음 — 앱/개발자가 직접 저장하지 않음. 광고 개인화는 Google 계정 설정에서 관리 |
| 독립적인 보안 검토를 받았습니까? | 아니오 |

운동 기록·촬영 영상 등 앱 자체 데이터는 여전히 기기 로컬에만 저장되고 수집 대상이 아닙니다 —
Data Safety 양식에서 광고 ID 외 다른 데이터 유형은 계속 "수집 없음"으로 답합니다.

## 참고

- 앱 아이콘(512×512), 피처 그래픽(1024×500)은 `store-assets/android/`에 생성되어 있음 (`npm run assets:icons`로 재생성)
- 개인정보처리방침 URL: https://hiddenliv.github.io/RNProject/
- **제출 전 확인**: `app.json`의 `react-native-google-mobile-ads` 플러그인 설정(`androidAppId`/`iosAppId`)과 `src/lib/ads.ts`의 광고 단위 ID가 아직 구글 샘플/플레이스홀더 값이다. AdMob 콘솔에서 앱·광고 단위를 등록해 실제 ID로 교체하지 않으면 프로덕션 빌드에서 광고가 나가지 않는다.

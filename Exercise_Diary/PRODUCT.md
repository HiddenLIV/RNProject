## Platform

adaptive

## Users

헬스장·집에서 혼자 운동하는 개인 사용자. 턱걸이·팔굽혀펴기·데드행·플랭크 같은 운동을 커스텀 종목으로 등록해 측정하고 기록을 쌓는다. 트레이너·그룹·소셜 기능은 대상이 아니다.

## Product Purpose

시간형(데드행·플랭크)과 횟수·세트형(턱걸이·팔굽혀펴기·스쿼트·런지 등) 운동을 사용자가 직접 커스터마이징해 측정·기록하는 개인용 운동 일지. 서버 전송 없이 모든 기록을 기기 로컬에만 저장한다. 성공은 사용자가 자신의 운동을 정확히 기록하고 최고 기록(PR)의 추이를 확인할 수 있는 것.

## Positioning

경쟁 운동 기록 앱 대비 차별점:
- **프라이버시**: 로컬 전용 저장, 계정가입/클라우드 트래킹 없음
- **완전한 커스터마이징**: 프리셋에 없는 운동도 이름·아이콘·색·측정 방식(시간/횟수·세트)·무게 기록 여부를 자유롭게 정의
- **자세 안내 영상 통합**: 유튜브 검색으로 자세 영상을 종목에 바로 연결해 측정 화면에서 재생
- **정확한 타이머 정밀도**: `setInterval` 누적이 아닌 `Date.now()` 경과 시간 기반 타이머로 백그라운드 전환·프레임 드랍에도 오차 없음

## Operating Context

- 헬스장 또는 집에서 운동 도중 스마트폰을 보며 사용 (한 손 조작, 짧은 세션 반복)
- 시간형 운동: 준비 카운트다운 + 벨 간격 알림으로 진행
- 횟수·세트형 운동: 세트 사이 휴식 타이머, 세트별 기록 누적
- 카메라로 운동 영상을 찍어 기기에 저장하고 다시 재생
- 데이터 백업/복원은 수동 파일 export/import (자동 클라우드 백업 없음 — 로드맵에서 격차로 식별됨)

## Capabilities and Constraints

- 로컬 데이터 저장만 사용 (`@react-native-async-storage/async-storage`), 서버 전송 없음
- 타이머는 `Date.now()` 기준 경과 시간 계산 (백그라운드·프레임 드랍 오차 방지)
- 운동별 최고 기록(PR), 세트별 상세 기록, 기록 시간 보정 기능
- 라이트/다크 테마 커스터마이징, 다국어(한국어/영어/일본어/중국어) 지원
- 배너 광고(AdMob)가 유일한 수익원 — 프리미엄 구독 등은 로드맵 Phase 3 검토 단계로 미확정
- 첫 실행 온보딩, 홈 화면 도움말 제공
- **미확정/현재 부재** (제품 사실로만 기록, future work가 임의로 채우지 않음): 리텐션 장치(알림·스트릭·목표) 없음, 진척 시각화(캘린더 히트맵·그래프) 없음, 자동 클라우드 백업 없음, 태블릿/가로모드 레이아웃 미고려, 자동 테스트·에러 리포팅 없음

## Brand Commitments

- 앱 이름: "HiddenReps" (한국어 표기 "나의 운동 일지"), 저장소 디렉터리명은 이전 이름 `Exercise_Diary`를 그대로 사용
- 패키지 식별자: `com.hiddenlab.hiddenreps`
- 현재 테마: 다크 + 마젠타 (팔레트가 과거 여러 차례 바뀐 이력이 있어, 색상 작업 전 `src/theme.ts`·`src/lib/themePresets.ts`를 항상 직접 확인)

## Product Principles

1. 기록은 사용자 기기를 벗어나지 않는다 — 서버 전송 없는 로컬 우선 설계를 모든 기능에서 유지
2. 프리셋보다 커스터마이징을 우선한다 — 운동 종류·측정 방식을 사용자가 정의하는 유연성이 핵심 가치
3. 타이머 정확도는 타협하지 않는다 — 경과 시간 기반 계산 원칙을 모든 신규 타이머 기능에 적용
4. 두 플랫폼(iOS/Android)에서 동일한 커스텀 디자인 언어를 유지한다 — OS 네이티브 룩을 따로 흉내내지 않는다
5. 측정 도구로서의 신뢰성이 먼저, 리텐션 장치는 그 위에 얹는다 — 로드맵 Phase 1이 안정성/기반, Phase 2부터 습관 형성 장치
